## 1. 자동 활성화에 대한 긍정 응답

수기 메모는 현재 동작으로 사거리 내 적 수가 많은 터렛부터 켜고, 같은 경우 화력을 기준으로 정한다고 설명한다. 자동 활성화 시 전체 터렛을 일시에 끈 뒤 전력 회복 시간을 거쳐 다시 켜며, 켤 터렛을 예약해 켜짐을 보장하려는 방향 아래에 “굳!”이라는 긍정 응답이 있다.

이는 해당 설명에 대한 긍정 반응의 근거다. 동률의 정확한 화력 지표, 예약 대상·취소·실패 처리, 전체 터렛의 범위, 자원 부족·파괴·잠금 변경 때의 보장 조건과 기존 구현의 완전 일치 여부는 이 메모만으로 확정하지 않는다. API·실제 실행 상태는 [현행 터렛 가이드](../architecture/turret-system-guide.md)를 별도로 확인한다.

## 2. 현장과 우주선의 행위 구분안

| 위치·귀속 | 수기에 적힌 항목 | 확인할 경계 |
| --- | --- | --- |
| 필드·스테이지 귀속 | 전력량, CU에서 자동 활성화·전술 지도·점유된 땅의 원격 터렛 작동, 무기 선택 | 개별 켜기/끄기는 물음표가 붙어 있음. CU 전용 범위와 UI·권한·점유 판정 미확정 |
| 필드·전역 | 터렛·CU 업그레이드 | 전역 성장의 저장·비용·현장 허용 범위 추가 확인 |
| 우주선·전역 | Player·무기·터렛·CU 업그레이드 | 현장 성장과 중복되는 항목의 책임·저장 경계 추가 확인 |
| 터렛 승급 | 승급 권한은 우주선, 실행은 터렛에 직접 접근 | 권한 해금과 실제 승급 조작을 분리한 안. 확정 API·거리·비용은 없음 |

최종 합의 표시가 없는 항목을 즉시 확정된 제품 정책이나 완료 과제로 바꾸지 않는다.

## 3. 성장·속성 검토안

- 터렛 승급과 고효율/고화력은 별개로 다룬다. 기존 두 갈래보다 Player와 같은 스킬 트리 성장으로 가자는 안을 기록했다.
- 터렛 스킬 트리 중간에 CU 업그레이드를 조건으로 두고, CU 업그레이드에 재화와 특정 Stage 클리어 조건을 넣는 구상이다. 트리 구조·재화량·해당 Stage는 미정이다.
- 터렛 속성 후보: 공격력, 과열까지 걸리는 양, 냉각 시간, 포신 회전 속도, 명중률, 초당 발사 수(rps), 체력.
- CU 속성 후보: 전력량, 체력, 전력 효율. 전력량과 전력 효율은 동시에 발현하지 않고 교차 강화한다는 메모가 있으며, 정확한 단계·배타 규칙은 확인이 필요하다.

기존 업그레이드 구현을 제거하거나 전역 저장 계약을 확정한 기록이 아니다. 실제 반영 전 Product Plan·성장 API와 함께 경계를 검토한다.

## 4. 날씨·시간 제안

| 발언 표시 | 제안 | 미확정·해석 주의 |
| --- | --- | --- |
| 이영빈 | 폭염 때 터렛 과열 속도 증가 | 원문 과부화 표현의 수치·정확한 속성 대응 미정 |
| 양현석 | 시간대 변경 때 가중 랜덤 날씨 변경. 안개는 사거리 저하, 비/눈은 냉각 속도 증가, 폭풍은 스폰 주기 증가·명중률 저하, 흐림은 스폰 주기 증가, 맑음은 기본값 | 가중치·시간대·수치 미정. '스폰 주기 증가'를 생성 빈도 증가나 감소로 임의 해석하지 않음 |
| 김진태 | 번개·오브젝트 상호작용, 터렛/CU 피격 시 무제한 전력 또는 HP 감소, 무제한 종료 시 자동 활성화 fallback, Player 피격 시 HP 감소 | 후보·예시이며 무제한 전력 채택·피해량·권한 계약 미정. Shader 사용 언급을 실제 구현 검증으로 취급하지 않음 |
| 황재동 | 밤에 강한 적, 우주선 복귀 권장, 필드 난도·보상 증가 | Tick off 의미·시간 정지 대상·위험 보상 미정 |
| 조수빈 | 밤 암살자 증가·Player 추적, 태양열 설정으로 총 전력 감소, Player 이로운 효과 추가 | 스폰량·전력 수치·효과·낮밤 적용 범위 미정 |

맵 기믹 안건은 취소선이 있으며 채택·철회 이유나 다른 환경 후보의 최종 처리는 적혀 있지 않다. 빈 안건 8·9와 추가 안건을 결정으로 만들지 않는다.
