# 2026-10-24 정기회의 검토 기록

수기만으로 작성했던 PR #552의 기록을 완성된 화자별 전사·요약과 대조해 보강했다. 아래 경과 시각은 원본 녹음 시작 이후이며 자동 인식·화자 정렬 오차가 있다. 녹음 시작 14:43:30.018 KST를 회의 시작 확정 시각으로 보지 않는다. 다섯 참석자 이름은 전사 자료의 기존 사용자 확인 매핑을 따르며, 발언자의 구현 보고를 독립 검증으로 확대하지 않는다.

## 1. 회의 운영 일정

| 회의 | 수기 일정 | 전사 대조·확인 경계 |
| --- | --- | --- |
| 스프린트 중간 점검 | 화요일 11시~11시 반 | 다음 주부터, 화요일·11시 발언 확인. 2시 질문은 11시로 정정됐고 30분은 수기 근거 [01:36:33–01:36:56] |
| 기획 보강 회의 | 금요일 2시~4시, 약 2~4주 | 금요일 기획 보강 발언은 있으나 시간·기간은 수기 근거 [01:35:26–01:35:30] |
| 정기회의 | 토요일 1시~3시 반 | 수기 근거. 녹음에서 전체 운영표를 다시 확정한 것으로 보지 않음 |

오전·오후, 정확한 시작·종료일은 미기재다. 다음 주 목요일 대면 모임·남은 CU 기획 논의 발언은 기존 금요일·토요일 운영과의 관계가 불명확하므로 별도 확인한다 [01:34:03–01:36:18]. 양현석이 황재동에게 중간 점검 캘린더 등록을 요청했지만 등록 완료는 미확인이다. 새 Sprint 번호·마감일이나 캘린더를 임의로 생성하지 않는다.

## 2. 전력 운용 방향

- 켜기는 별도 가동 준비 지연 없이 동작하는 설명이다. 수기의 「가동 시간 없음」을 무제한 연속 사격 시간으로 해석하지 않는다 [19:11–19:33].
- 정상 정지는 남은 과열을 자동 냉각한 뒤 꺼지고 그 단계에서 전력을 반환하는 방향이다. 버튼을 계속 누르는 냉각 조작이나 모든 전환에 동일한 고정 쿨타임을 추가하는 뜻이 아니다 [20:20–21:05].
- 파괴 후 쓰던 전력 일부를 계속 예약한다. 100 중 50 반환·50 예약은 설명 예시이며 정확한 비율·반환 시점은 미정이다 [21:08–21:54].
- 파괴 상태에서 수동으로 꺼 전력을 모두 회수하는 동작은 허용하지 않는 최종 정리를 따르며 복구가 필요하다 [21:56–23:07].
- 체력 감소만으로 별도 추가 불이익을 주지 않는 설명은 과열·파괴 예약 전력과 구분한다. 일반 HP 회복은 Repair, HP 0 파괴 후 복구는 Restore다 [17:54–18:12, 19:37–20:04, 01:23:30–01:23:37].

정확한 시간·냉각 곡선·반환 비율·상태 전이 API와 현재 구현 일치 여부는 후속 검증 대상이다.

## 3. 수리·복구 방향

- 우선 현재 Interaction range 안에서 Repair·Restore한다. 화면에 보이는 선택과 조작 가능 거리를 구분하며 실제 통합 플레이 후 범위를 조정한다 [01:23:37–01:24:25].
- 비용은 재화가 아니라 시간이다. 수리 드론은 보류한다 [01:25:21–01:26:21].
- 복구 취소 후 진행 게이지를 유지하는 방향이다. 70% 발언은 진행 예시인지 고정 유지율인지 불분명하므로 고정 감가율로 설정하지 않는다. 씬 이탈·저장·네트워크 유지 정책은 별도다 [01:26:21–01:27:03].
- 황재동은 Restore 진행 중을 파괴 상태로 취급해 몬스터가 해당 터렛을 공격하지 않는다고 설명했다. 일반 Repair와 구분하며 실제 게임 상태·실행은 미검증이다 [01:27:03–01:27:38].
- 별도 스패너 수리 무기를 휘두르는 조작 대신 상호작용 키를 누르는 동안 수리 상태로 들어가는 방향이다. 스패너 수리 모션은 유지할 수 있으며 근접 공격 무기는 별도로 다룬다. F키는 예시이고 최종 바인딩이 아니다 [01:29:45–01:31:58].
- 암살형이 수리 중인 Player를 우선 노리는 안은 제안이며 기존 감지만으로도 수리가 어려울 수 있다는 반론이 뒤따랐다. 돌진 속도·특별 가중치·감지 반경은 미정이다 [01:27:39–01:29:41, 01:32:15–01:33:56].

현재 main의 타격 수리 API를 이 시간 기반 상호작용 기획의 구현 완료로 간주하지 않는다. 모션 전체 제거로도 해석하지 않는다.

## 4. 성장·재화 검토

### 후반에 정리한 방향

- 몬스터 처치 경험치 → 레벨 업 → 스킬트리 토큰 → 스킬트리 성장. 경험치는 스테이지 종료 뒤에도 유지하는 방향이다. 토큰 지급 간격·개수·노드 가격은 미정이다 [01:01:04–01:01:17, 01:18:23–01:19:09, 01:22:23–01:22:40].
- 무기용·터렛용 Blueprint를 구분하고 업그레이드 시 해당 Blueprint와 재화를 함께 사용한다. 개별 터렛·등급별 청사진, 일반 몬스터의 재화1 지급 여부·멀티 보상 분배는 확정하지 않았다 [01:18:42–01:20:06].
- 터렛 레벨에 따라 Minor Upgrade의 상한을 두는 방향에 황재동이 동의했다. 레벨별 상한 2/3/5는 예시이며 최종 표가 아니다. Minor Upgrade 자체의 청사진 소비·비용표는 미정이다 [01:20:07–01:21:05].
- CU도 터렛 성장 체계에 포함하고 성장 시 HP·EP를 함께 올리는 방향이다. 황재동의 레벨별 외관 검토 의사는 아트 제작 완료가 아니다 [01:21:05–01:21:51].
- Player 기본 스탯·장비 강화와 스킬트리의 세부 경계, 장비 슬롯·수치·획득 경로는 미정이다. BFS/DFS 스킬트리는 의견이며 구조 확정이 아니다.

### 재화·드롭 후보와 미정 값

| 경로 | 기록한 보상 방향 | 확정하지 않은 값 |
| --- | --- | --- |
| 일반 몬스터 | 경험치, Blueprint 확률 드롭 검토 | 수기 0.000001%는 제안값. 재화1 지급 여부도 미정 |
| 보스 | Blueprint 확정 + 경험치 + 재화1 방향 | 보상 목록·수량·Blueprint 소비 명세 미정 |
| 중간 보스 | Blueprint 확률 드롭 + 경험치 + 재화1 방향 | 수기 50%는 제안값. 최종 확률 아님 |
| 레벨 업 | 스킬트리 토큰 | 지급 간격·개수·가격 미정 |

유료 재화는 임시 명칭 수준이다. 과금 상품·스킨·DLC 제안을 채택 정책으로 바꾸지 않는다. 맵 상호작용·메이저 스테이지 클리어 보상은 수기 취소선을 보존하며 확정 보상표에 추가하지 않는다. [01:02:01–01:13:18, 01:18:23–01:22:40]

위 성장 방향을 Stage 1 PoC 완료 조건이나 기존 M2/Deferred 범위의 자동 확대로 해석하지 않는다. 실제 저장·지급·Backend 구현도 미검증이다.

## 5. 몬스터 목표·스폰·성능

- 분대 단위로 가까운 터렛을 선택하며 밀집된 대상을 새 후보에서 제외하는 기본안을 시험한다. 스폰·목표 터렛 파괴 때 배정하고, 이동 중 수용량이 달라져도 기존 할당을 유지해 왕복을 피한다 [01:37–08:50].
- Player 감지·이탈 시 추적과 터렛 행동 복귀를 우선 시험한다. 감지 반경·원거리 집계·분대 예외·복귀 시 재선정은 미정이다 [05:33–06:38, 08:51–08:59].
- 필드 전체 몬스터 수에 별도 상한을 두지 않고 스폰량으로 조절하는 방향이다. 터렛별 수용량과 다른 개념이며 수용량 50은 예시다 [09:01–09:45].
- 이영빈은 반복 스폰 시 프레임 저하를 보고했다. 업데이트·렌더링 중 병목 원인이나 특정 개체 수 성능, ECS·배치 렌더링 효과는 검증되지 않았다 [15:36–16:43].
- 맵 외곽 유입·중간 생성, 씨앗/식물 스포너, 랜덤 투하·함정은 제안이다. 확정 구현·협업 담당이나 배치도 최종안으로 쓰지 않는다 [10:00–14:47].

재화·경험치·Blueprint의 최종 구현 담당·마감일은 명시적으로 확정되지 않았다. 기존 책임은 [Ownership](../team/TEAM_ROLE_OWNERSHIP.md)을 따르며 구현 보고·계획·검증 증거를 구분한다. 이 작업은 원본 녹음 직접 청취, 게임 실행, 이슈 발행이나 개발 완료 확인을 수행하지 않았다.
