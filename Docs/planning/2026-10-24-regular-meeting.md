# 2026-10-24 정기회의 검토 기록

기준 자료: 공유 드라이브 회의록의 2026-10-24_정기회의_녹음본/20261024.md
상태: 수기 회의록 기준 제품 방향·운영 일정 정리 / 구현·실행 검증 아님

[문서 목차](../README.md) · [Product Plan](../product/PROJECT_PLAN.md) · [협업 규칙](../team/TEAM_WORKFLOW.md)

수기 기록에는 발언자별 본문과 일부 안건이 비어 있다. 적힌 내용만 반영하며 참석자별 진척이나 수락하지 않은 작업 담당·마감일을 추정하지 않는다. 음성·전사본과 대조 검수하지 않았다.

## 1. 회의 운영 일정

| 회의 | 원문 일정 | 기간·확인 경계 |
| --- | --- | --- |
| 스프린트 중간 점검 | 화요일 11시~11시 반 | 반복 운영 일정. 새로운 Sprint 번호나 종료일 확정이 아님 |
| 기획 보강 회의 | 금요일 2시~4시 | 약 2~4주 진행 방향. 정확한 시작·종료일 미기재 |
| 정기회의 | 토요일 1시~3시 반 | 오전·오후와 시간대는 수기 원문에 별도 표기 없음 |

표의 시각은 원문 표기를 보존했다. 정확한 캘린더 시각·초대 생성은 확인 후 진행한다.

## 2. 전력 운용 방향

- 터렛을 껐다가 켤 때 전력이 보충되는 데 일정 시간이 걸리는 방향이다. 추가 냉각 시간은 후보이며 지연 길이·반환 시점·재가동 조건은 미정이다.
- 별도의 가동 시간 제한은 두지 않는다. 복구와 수리에는 시간이 든다.
- 파괴 시 전력을 전부 돌려주지 않고 대기 전력을 남기는 방향이다. 반환·손실 비율과 대기 전력 수치는 기록에 없다. 기존 비율 API를 최종 수치로 고정하지 않는다.
- 파괴된 터렛은 끌 수 없고 반드시 수리해야 한다는 상태 전이 제약을 기록했다. 파괴 후 복구와 일반 수리의 정확한 전이·입력·전력 예약 계약은 추가 설계한다.

## 3. 수리·복구 방향

- 기본 Interaction range 안에서 수리·복구한다. 정확한 범위는 미기재다.
- 비용은 재화가 아니라 시간이다. 수리 드론은 보류한다.
- 복구 중 취소해도 진행 게이지를 유지한다. 씬 이탈·재시작·저장·네트워크까지 유지한다는 뜻은 아니다.
- 키를 누르고 있는 동안 수리 상태로 진입하고 스패너를 없애는 표현 방향을 기록했다. 키 지정, 무기 전환·표시 범위, 공격·이동·피격 중단 규칙은 미정이다.
- 암살자가 빠르게 접근하는 연출은 참고 아이디어다. 수리 상태를 감지하는 AI 기능이나 속도 수치가 확정된 것으로 보지 않는다.

현재 main의 스패너 타격 수리 API와 이 회의의 시간 기반 수리·복구 방향은 구분한다. 회의 기록을 구현 또는 PlayMode 통과로 표시하지 않는다.

## 4. 성장·재화 검토

업그레이드 후보는 Player 스킬트리·장비(Minor Upgrade), 터렛 CU의 HP/EP·Turret Level·고효율/고화력 Minor Upgrade, 무기 업그레이드다. 스킬트리를 BFS/DFS로 다루자는 내용은 양현석의 의견이며 구조 확정이 아니다.

재화 후보는 Player 경험치, 스킬트리 토큰, 이름 미정의 재화1, Blueprint와 유료 재화다. 유료 재화의 별표는 운영·과금 정책 확정으로 해석하지 않는다.

| 획득 경로 후보 | 수기에 적힌 보상 | 수치·확정 경계 |
| --- | --- | --- |
| 일반 몬스터 | 터렛/무기 Blueprint + 경험치 | Blueprint 확률 원문 0.000001%. 최종 밸런스 승인 여부 미확인 |
| 보스 | 확정 Blueprint + 경험치 + 재화1 | 수량·종류·중복 처리 미정 |
| 중간 보스 | Blueprint + 경험치 + 재화1 | Blueprint 확률 원문 50%. 최종 밸런스 승인 여부 미확인 |
| 레벨 업 | 스킬트리 토큰 | 지급량·사용 규칙 미정 |

맵 상호작용과 메이저 스테이지 클리어 보상 행은 수기에서 취소선 처리돼 있어 채택하지 않는다. 위 항목은 검토 후보이며 Stage 1 PoC 범위나 기존 Deferred를 자동 변경하지 않는다.

## 5. 후속 확인

- 전력 보충 지연, 대기 전력·반환 비율과 파괴 상태 전이의 실제 계약을 결정한다.
- 키 유지 수리, 복구 취소·재개와 Interaction range의 구현·검증 기준을 정한다.
- Blueprint 확률·보상 수량·사용처와 과금 관련 미결 사항을 후속 기획에서 검토한다.
- 회의의 오전·오후, 시작·종료일과 실제 담당자 수락·마감일은 별도 확인한다.

현재 책임 영역은 [Ownership](../team/TEAM_ROLE_OWNERSHIP.md)을 따르며 새 업무 배정·완료·검증 증거를 이 기록만으로 생성하지 않는다.
