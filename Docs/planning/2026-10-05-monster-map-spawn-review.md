`Normal`과 최대 10마리로 읽히는 값은 플래너 확인 과정의 임시값으로 언급됐다. 최종 웨이브·밸런스 규칙으로 채택하지 않는다. 이 논의는 [Stage 1의 전제 1·2 재미 검증](SPRINT_1_STAGE_1_POC.md)을 위한 생성 확인을 돕는 것이며, 세 전선이나 보스 위치의 완성·PoC 통과를 선언하지 않는다.

## 후속 확인

1. 루트 스크립트, 스폰 포인트 ID와 구역·레인 연결을 실제 Scene에서 확인한다.
2. `Spawn`을 호출할 대상·인자·초기화 순서를 코드에서 확인한 뒤 생성 결과와 오류를 남긴다.
3. 이동까지 검증할 때 필요한 네트워크 매니저 상태를 확인한다. 생성 확인과 이동 검증을 별도로 기록한다.
4. 폭에 맞는 문·통로 형태와 접근 시 문 열림을 실제 Build에서 확인한다.

업무 주체로 언급된 김진태·조수빈의 개별 발언 연결은 음성 기반 자동 추정이다. 참석자 두 명은 사용자 확인이지만 이번 문서에서 새 담당자나 마감을 확정하지 않는다. 코어와 스폰 호출 책임도 미정이다.
