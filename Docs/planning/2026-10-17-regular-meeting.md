# 2026-10-17 정기회의 검토 기록

기준일: 2026-10-17
상태: 회의 방향·후속 작업 정리 / 상세 제품 규칙과 구현 검증은 미완료

[문서 목차](../README.md) · [Product Plan](../product/PROJECT_PLAN.md) · [10월 10일 회의 검토 기록](2026-10-10-regular-meeting.md)

> 근거는 10월 17일 화자별 자동 전사문과 같은 폴더의 수기 회의록이다. 녹음 직접 청취와 게임 실행 검증은 하지 않았다. 아래에서 회의 중 구현 보고, 합의 방향, 시험용 값, 미결 사항을 구분한다.

## 핵심 정리

1. **Z-Order와 Y/Z 매핑 문제를 우선 수정한다.** 조수빈이 먼저 수정하고 추가 검토한다. Y 기반 Z 값이 다른 렌더 구간을 침범하지 않도록 기존 정렬 기준에 맞춰 매핑·Clamp하는 방향이다. 최종 상수표나 렌더링 성능 결과를 확정하지 않았다.
2. **군중 이동은 밀어내기부터 시험한다.** 먼저 뒤의 몬스터가 앞의 몬스터를 밀어내고, 필요하면 빈 공간 우회 처리를 추가한다. 질량과 속도는 시험 후 정하며 예시 수치를 고정하지 않는다.
3. **터렛 해금·활성화·지역 점유는 서로 다른 상태다.** 점유는 CU 주변에서 인접 영역으로 이어지는 방향으로 설명했다. 먼 터렛을 하나 켜는 것만으로 그 위치가 즉시 점유되지는 않는다. 점유율 기준 영역은 전체 맵이 아니라 터렛 배치 등을 기준으로 한 점유 가능 영역으로 설명했지만, 외곽선과 셀 판정식은 미정이다.
4. **송신탑을 정적 지역 해금의 기본 시제품으로 만들어 기획을 더해보는 방향에 동의했다.** 김진태에게 시제품 맵 제작 요청이 있었다. 송신탑 방식, CU 거리 해금, 동적 지역 가운데 최종 게임 방식을 선택하지 않았다.
5. **승리 흐름은 점유 이후 보스전으로 이어져 보스를 처치하는 방향으로 검토한다.** CU 파괴는 게임오버로 정리했다. Player 사망은 저장 시점 복귀를 안전장치 방향으로 두고, 약 3회는 우선 시험할 값으로만 다룬다. 정확한 승리 게이트, 보스 공간·기믹, 체크포인트와 저장 필드는 미정이다.
6. **각 파트의 현재 성장·업그레이드·사용 위치를 문서화한다.** 양현석이 정리 문서를 준비하고 Player·스킬·Turret·Spaceship·CU 관련 파트가 알고 있는 기능과 규칙을 회의 당일 또는 다음 날까지 적도록 요청했다. 이는 구현이나 완료 보고가 아니다.

## 결정 방향과 설계 검토

### Z-Order, 충돌과 군중 이동

- 기존 렌더 순서 기준을 따르고 Y 위치를 Z 값으로 매핑할 때 범위 충돌을 막도록 Clamp한다. 조수빈이 우선 수정한 뒤 추가 검토한다. 이동·방향 계산은 2D 기준으로 분리한다.
- 발 부위 중심의 충돌 기준과 시각적 겹침은 피격 판정 및 개체 간 충돌과 구분한다. 상세 Collider 구성은 후속 검토다.
- 군중은 밀어내기를 먼저 구현·시험하고, 결과에 따라 Steering/Crowd Path Following 기반 빈 공간 우회를 추가할지 판단한다. 크기별 질량·속도는 시험으로 정한다.
- Enemy 타깃 점수 유지 여부와 움직이는 Player에 대한 경로 재탐색은 시험 이후 양현석·조수빈이 별도로 논의한다.

### 날씨와 전투 검토

- 낮·밤은 시간 축, 날씨는 별도 축으로 검토한다. 날씨 효과와 변경 트리거는 아이디어를 모은 뒤 정한다.
- 개발자용 날씨 조절 도구와 셰이더·후처리 연출을 시도하는 방향이 나왔다. 비에 따른 군집 증가, 폭염의 과열, 사거리 변화, 번개 효과 등은 후보 예시이며 확정 규칙이 아니다.
- 기본 공격을 조정한 뒤 몬스터와 전투해 판단한다. 근접 탄환 중첩과 보스 방패 파괴는 제안이며 정식 사양으로 확정하지 않았다.
- 기존 4방향 몬스터 팩을 우선 활용하는 방향이 언급됐다. 최종 스프라이트 방향 수, 공중 몬스터 역할, Enemy 종류·스킬·공격 규칙은 미정이다.

### 해금, 활성화와 점유

- 전제 1은 터렛 개별 활성화를 통한 동적 지역 구상, 전제 2는 정해진 지역의 터렛 사용 권한을 먼저 여는 구상으로 비교한다. 이번 회의에서 최종안을 채택하거나 Stage 1 PoC 판정을 완료하지 않았다.
- 두 구상 모두 점유는 CU 주변에서 인접한 영역으로 이어지는 방향으로 설명했다. 멀리 떨어진 터렛을 활성화해도 해당 위치가 바로 점유되는 것은 아니다. 불리한 전투로 점유 영역이 줄어들 수 있다는 설명도 나왔다.
- 해금 구역이 전부 열려도 점유를 잃을 수 있다. 해금, 터렛 활성화, 실제 점유를 서로 대체 가능한 상태로 기록하지 않는다.
- 점유율의 분모는 전투가 없는 모서리나 접근 불가 영역을 포함한 전체 맵이 아니라, 터렛 배치 등을 바탕으로 구성한 최대 점유 가능 영역으로 설명했다. 정확한 폴리곤, 셀 연결, 우세·후퇴 수식과 갱신 주기는 미정이다.
- 정적 해금의 시제품은 송신탑으로 시작하는 방향이다. 구역 경계·점령 조건·복원 상호작용·송신탑 파괴 영향·터렛 재잠금은 확정하지 않았다. 김진태에게 맵 제작 요청이 있었으며 납기나 완료 상태를 확인한 것은 아니다.

### 승리, 게임오버와 안전장치

- 점유 이후 보스전으로 진입해 보스를 처치하는 승리 흐름을 검토했다. 별도 맵인지 현재 씬의 잠금 구역을 여는지, 진입 점유율, 승리 완료 판정과 전투 기믹은 미정이다.
- CU 파괴는 게임오버로 정리했다. 구현 완료나 게임오버 UI 완료를 뜻하지 않는다.
- Player 사망은 저장된 시점으로 복귀하는 방향이다. 약 3회는 밸런싱 전 우선 시험값이다. 해금이 없는 동적 전제의 저장 시점, 최종 복귀 횟수·저장 자료·복원 절차는 결정되지 않았다.
- 스냅샷 후보에 Player·터렛·업그레이드·점유·스포너·날씨·시간이 언급됐지만, 모든 개체 상태를 저장·복원하는 계약은 정하지 않았다. 몬스터 개체 수는 스포너로 재구성하는 방향이 언급됐다.

## 회의 중 보고와 검증 경계

- 양현석은 네트워크 기반 작업을 약 70%라고 보고했고, 정적·동적 지역 선택 시제품이 있다고 설명했다. 이 수치는 발언 당시 보고이며 코드·병합·통합 검증으로 확인하지 않았다.
- 이영빈은 기본 무기 외 Player 작업을 보고했고, 김진태는 간단한 날씨 전환 표현을, 조수빈은 Enemy 경로 작업을 설명했다. 황재동은 터렛 스프린트가 끝났다고 수기에 적었으나, 각 보고를 저장소 상태나 실행 결과로 간주하지 않는다.
- Player 기본 공격·터렛 수리 시험은 계속한다. 회의 초반의 “몬스터가 터렛을 공격하지 않는다”는 보고는 조수빈이 최신 PR에서 공격을 확인했다고 후반에 보완했다. Player 타깃 공격과 수리 시험의 실제 결과는 별도 확인 대상이다.
- 자동 활성화 시연에 대해 적 밀집과 전력 효율을 고려한다고 설명했고, 전체 터렛을 끈 뒤 전력이 회복되는 대로 순차 활성화하는 동작도 설명했다. 하지만 현재 main의 [터렛 가이드](../architecture/turret-system-guide.md)는 기본 순위를 적 수로 기록한다. 회의 설명의 전력 효율 순위는 코드·시연 결과로 별도 대조하기 전까지 구현 계약으로 바꾸지 않는다. 1분 간격과 전력 50은 설명 중 나온 현재 동작·예시이며 밸런스 규칙 확정이 아니다.
- 시작 시 Enemy 약 100마리와 장기적으로 수천 마리라는 수치가 대화에 나왔으나 성능 목표나 검증 통과 기준이 아니다. Pooling 등 최적화도 추가 조사 대상이다.

## 미결 사항

- 전제 1·2와 거리 기반·송신탑 해금의 비교 기준, 시험 결과, 최종 선택 및 구현 순서.
- 실제 점유 영역 형상, 연결·우세·후퇴 판정과 갱신 정책.
- 송신탑 점령·복원·파괴 영향, 지역별 터렛 소속 및 재잠금 규칙.
- 보스전 진입 조건·공간·Scene·기믹·승리 판정 세부.
- Player 복귀 횟수, 저장 시점·필드·복원 규칙.
- 날씨 효과·트리거, 기본 공격, 몬스터 역할·스킬, 최종 성능 목표.
- 성장·업그레이드 세부와 영역별 이용 위치, 추가 기획 회의의 실제 일정.
