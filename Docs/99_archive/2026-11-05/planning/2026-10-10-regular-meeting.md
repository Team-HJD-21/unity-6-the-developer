# 2026-10-10 정기회의 검토 기록

기준일: 2026-10-10 · 상태: 실행 기준에 반영할 결정과 후속 설계 항목

> 근거는 공유 회의록과 그 안의 화자별 전사다. 자동 인식 전사이며 녹음을 직접 청취해 검수하지 않았다. 아래 타임스탬프와 용어에는 오차가 있을 수 있으므로 불명확한 세부 규칙은 확정하지 않았다. 정기회의 후반의 황재동·양현석 추가 논의는 별도 구분했다.

## 핵심 정리

- 팀은 M1과 M2 사이에 있으며, 레거시 코드 없이 실행하는 M1 목표에는 가까워졌다는 의견이 있었다. 재미 검증과 전체 완료 여부는 확인되지 않았다. M2는 플레이 가능한 맵과 Spaceship 왕복 흐름을 만드는 단계로 설명됐으며, M1 완료나 M2 일정이 새로 확정된 것은 아니다. [00:20–04:05]
- 플레이어가 터렛을 직접 수리하는 기본 기능을 두는 방향에 동의했다. 수리 속도·수치와 수리 무기 구현은 별도 검토가 필요하다. [13:00–22:52]
- 잠긴 터렛은 파괴 불가로 두고, 해금 후 별도 수리 없이 사용할 수 있게 한다. 전력 부족으로 플레이어가 비활성화한 터렛은 잠금 상태와 다르며 공격 가능한 대상으로 구분한다. [36:48–40:13, 46:26–47:18]
- 터렛 배치 유효성 검사에는 지형·물·터렛·몬스터와의 겹침 판정이 필요하다. 현재 물 타일의 아웃라인 콜라이더는 내부 설치를 막지 못할 수 있다. 양현석이 Unity 동작과 판정 방식을 조사하고 이영빈과 더 살펴보기로 했다. [23:29–36:24]
- 자동 활성화는 터렛 사거리 안의 적 수를 먼저 보고, 이후 전력 대비 화력 효율을 고려하는 안이 설명됐다. 1분 간격은 구상으로만 언급됐으며 실제 동작과 최종 간격·순위는 검증되지 않았다. [56:13–58:40]
- 추가회의에서 터렛 지역·해금 자료와 전선 토폴로지를 분리할 필요를 논의했다. 황재동이 그리드 작업을 진행하고 양현석이 기존 클래스·자료 구조를 설명하기로 했다. 지역 모델·그리드 해상도·저장 자료·토폴로지 연결 방식은 미정이다. [1:08:15–1:31:17]

## 합의된 제품 방향

### 터렛 피해와 수리

- 플레이어가 터렛을 직접 찾아가 수리하는 기본 기능을 둔다.
- 터렛 체력이 줄어들 때 추가 성능 저하를 주는지는 보류한다. 게임이 지나치게 쉬울 경우 밸런싱 단계에서 다시 검토한다.
- 자동 수리 드론·로봇은 편의 아이템 아이디어다. 지급·판매·가격·재화와 이를 전제로 한 밸런스는 결정하지 않았다.

### 잠금·해금과 공격 대상

- 잠긴 터렛은 파괴되지 않는다.
- 해금된 터렛은 별도 수리 없이 사용할 수 있게 한다. 해금이 자동 활성화나 전력 예약을 뜻하지는 않는다.
- 전력이 부족해 플레이어가 직접 끈 터렛은 잠긴 터렛과 구별하며 적의 공격 대상이 될 수 있다.
- 현재 main의 터렛 가이드는 CU 위치와 Grid 셀 거리를 이용한 구역 해금 프로토타입을 설명한다. 회의에서는 실제 지역 정책·데이터·저장 구조를 확정하지 않았다. 이를 이름이 붙은 고정 Region이나 `RegionId` 계약으로 해석하지 않는다.

### 자동 활성화

사거리 안의 적 수를 우선하고 전력 대비 DPS 효율을 다음 평가 기준으로 두는 안이 제시됐다. 코드에 현재 구현된 적 수순 활성화는 이 회의에서 설명된 전체 평가 규칙과 동일하다고 간주하지 않는다. 1분 사용 간격도 제품 규칙으로 승인된 것이 아니다.

| 양현석 | 네트워크 기반 작업 | 이번 주 우선 작업으로 언급, 상세 범위·일정 미정 |

## 추가 논의와 미정 사항

- 지역 해금이 고정 구역, CU로부터 거리, 동적 점유 중 무엇을 따를지와 해금 단위는 미정이다.
- 현재 Grid를 쓸지 더 촘촘한 별도 Grid를 쓸지, 셀에 지역 ID를 저장할지 조회 시 계산할지 결정되지 않았다.
- 전선 토폴로지와 지역·해금 Grid는 역할을 구분할 필요가 있다. 토폴로지를 Grid에 투영할지, 지역 점유와 어떻게 결합할지는 추가 설계 대상이다.
- 터렛 설치를 위한 지형·충돌 검사 방식, CU 기본 기능, 원격 복귀, 미니맵·전장 상태 UI도 미정이다.
- 정기회의에서 네트워크 작업 일정과 M1/M2 경계는 정해지지 않았다. 시험 기간, 기능 완료일, 새 Sprint, 담당자 재배정도 새로 확정하지 않았다.
- 양현석* 움직이는 대상, 환경 기믹, 레이저 터렛은 보고·제안된 작업 방향이며 완료 상태를 확인하지 않았다.
