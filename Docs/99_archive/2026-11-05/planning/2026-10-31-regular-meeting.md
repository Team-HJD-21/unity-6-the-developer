# 2026-10-31 정기회의 검토 기록

기준일: 2026-11-01 (10월 31일 회의 내용의 사용자 확인 정정)
상태: 전체 개인별 자동 전사·갱신 수기 대조 / 제품 방향·설계 미정·실행 보고 분리

참석: 황재동·양현석·김진태·이영빈·조수빈. info.txt에 다섯 계정 트랙이 있고 전원 발언이 인식됐다. 공유 드라이브 `The-Developer-V2/회의록/2026-10-31_정기회의_녹음본`의 회의록, `2026-10-31_화자별전사.md`, 갱신 수기 `20261031.md`를 근거로 한다. 수기는 작업 중 빈 양식에서 실제 내용으로 갱신되어 최종본을 대조했다. 전사에 수기 문장을 추가하지 않았다.

[전날 기획 보강회의](https://github.com/Team-HJD-21/unity-6-the-developer/blob/1a03e9a9164e5db94cbc8775162467d08cf63a3b/Docs/planning/2026-10-30-planning-review.md)의 후속 안건이다. 다섯 AAC 전체 약 64분을 로컬 자동 전사하고 주요 10구간을 같은 small 모델로 자동 재전사했다. 직접 청취·코드 실행·Unity/Scene 검증은 하지 않았다. 아래 시각은 녹음 시작 이후 경과 시간이다.

## 1. 대응 자료와 보스의 우선순위

[00:01:36–00:06:37]

- Enemy·Turret·Player 프로퍼티/스킬 자료를 Excel 등 같은 형식으로 Drive에 정리하고 실제 수치가 바뀌면 함께 갱신한다.
- 양현석은 폴더·기존 자료 정리, 황재동은 터렛 자료 신규 작성을 언급했다. Player 자료는 이영빈과 양현석이 조율할 후속이다. 새 대응표·밸런스 수치가 작성 완료된 것은 아니다.
- 기본 게임 루프 통합 뒤 보스 상세를 논의한다. 기존 보스 승리 방향을 폐기하거나 현재 PoC에 완성된 보스를 추가하지 않는다.

## 2. 스폰 압력과 개별 Enemy 행동 구분

[00:07:38–00:10:46]

- 목표·추격·이동·분대 행동은 양현석과 조수빈이 이전에 정했다는 보고로 넘겼다. 새로운 AI 규칙이나 구현 완료를 이 회의에서 입증하지 않는다.
- 구역별 압력·예산·주기는 실제 시험 후 정한다. 플레이어가 특정 구역에서 멀어졌다는 이유로 스폰을 유도/억제하지 않고 전선·구역·이벤트·날씨를 기준으로 다루는 방향이다.
- **개별 적이 Player 수리 상태를 참조하는 동작은 별도다.** “Player와 무관”을 모든 AI에서 Player를 무시하는 규칙으로 확장하지 않는다.

## 3. 점령·스포너 영향과 그룹화

[00:10:56–00:18:14]

- 점령된 구역 내부/연관 스포너의 영향이 약해지거나 사라지고, 점령을 잃으면 다시 돌아오는 방향이다. 녹음의 “해금”이라는 표현을 **점령**으로 정정했다. 해금·터렛 활성화·점유를 구분한다.
- 스포너가 실제 점유 영역 밖에 있을 수 있어 전체 점유율을 쓰는 안이 나왔으나, 왼쪽만 점령해도 오른쪽 스포너까지 줄어드는 반례가 제기됐다. 전체 점유율 단일 임계치·거리순 OFF를 확정하지 않는다.
- **조수빈이 스포너 그룹화를 이번 작업 주기에 진행**하기로 답했다. 기존 영역 식별자와 그룹 관리의 실제 구현 여부는 대화에서도 불확실했다. 코드 ID·API 계약이나 완료 상태를 추측하지 않는다.
- 지역별 영향 감소·완전 OFF·예산/빈도 변화·재활성 조건은 후속 설계다. 점유율, 구역 연결, CU 위치와 전제 1/2의 차이를 시험해야 한다.

## 4. 레벨 디자인과 후방 터렛

[00:18:18–00:28:33]

현재 테스트 배치를 전략 배치 완성본으로 취급하지 않는다. 몬스터 분대 프리셋·스폰·이벤트를 연동하고 터렛/스포너를 실제로 놓아 시험한 뒤 반복 수정하는 흐름이다. 갱신 수기의 “몬스터 스폰·비동기 이벤트 기반 스폰 선 개발”도 같은 선행 작업으로 기록하되, 특정 async API나 실행 완료로 해석하지 않는다.

외곽부터 공격하는 적을 상대할 때 후방 터렛을 켤 이유가 부족할 수 있다는 문제를 확인했다. 내부 기습 이벤트·잔여 스폰·지원 화력은 후보이며 하나를 최종 채택하지 않았다.

- 김진태는 Core PR 이해·연동과 함께 배치를 바꿔 보겠다고 답했다. 화요일까지는 애매하고 금요일 기획회의 무렵을 목표로 언급했으므로 화요일 확정 완료로 바꾸지 않는다. [00:25:05–00:26:39]
- 양현석·조수빈·김진태가 실제 테스트·시뮬레이션을 보며 계속 조율한다. 전제 1/2는 아직 선택하지 않았고 11월 안에 골라야 한다는 목표를 언급했다. [00:27:41–00:28:33]

## 5. 우주선 필드 정지·재방문·실패 보상

**우주선 진입 시 필드 정지 재확인** [00:33:36–00:34:55]

김진태가 시간뿐 아니라 몬스터·터렛도 멈추는 것인지 물었고 황재동·양현석이 멈추는 방향이라고 답했다. 전날 정지 논의의 범위를 오늘 재확인했다. 진입/복귀·저장·정지 API와 멀티플레이 처리까지 확정한 것은 아니다. 현장 CU 업그레이드까지 같은 정지 조건으로 확대하지 않는다.

**이전 행성 재방문** [00:28:51–00:30:19, 00:35:29–00:41:34]

돌아갈 수 있게 하되 **점령한 상태를 유지해 보여 주는 방향**이다. 갱신 수기는 몬스터 처치 이벤트와 재보상을 반복하지 않는다고 명시한다. 전투를 초기화해 파밍을 강제하는 구조로 읽지 않는다. NPC·이스터에그·미획득 청사진·별도 자원 수급처·자동 생산 구상은 구현 범위/방법이 남았고 후반에 자세한 논의를 미뤘다. 수기와 녹음에 나왔다는 이유만으로 자동 생산·타이쿤·DLC를 신규 필수 기능으로 추가하지 않는다.

**별도 실패 보상 제외 방향** [00:31:24–00:32:36]

보상은 몬스터·중간 보스 등 진행 과정에서 얻으며 실패 결과에 별도 보상을 추가하지 않는 방향이다. 이미 얻은 재화의 체크포인트 롤백/보존 범위, 사망 복귀 계약은 별도다.

## 6. 인게임 도감·지원형 Enemy·스폰 책임

**도감** [00:49:46–00:53:43]

드라이브의 몬스터 목록과 인게임 열람 도감을 구분했다. 10월 3일의 “도감 등록은 계속되고 있습니다” 발언을 찾아 읽었지만, 데이터 등록은 열람 UI 구현 완료와 다르다. 새로운 도감 UI 담당·마감·완료 증거를 확정하지 않았다.

**지원형·사망 연출** [00:52:06–00:58:56]

- 일회용 설치 제안과 공격하지 못하는 지원형의 남은 역할을 논의했다. 본체가 시설처럼 변하는 안을 검토하고 에셋을 확인한다. 동작 규칙 전체를 확정한 것은 아니다.
- 조수빈은 사망 스프라이트를 먼저 시험하고 어렵다면 투명해지며 사라지는 방식으로 하겠다고 답했다. 완료된 애니메이션·전 몬스터 공통 규격이 아니다. 기준점 발음은 불명확해 특정 좌표 규칙을 만들지 않는다.

**Encounter/SpawnPlanner** [00:55:05–00:57:21]

조수빈은 스포너별 할당량과 구체 생성 대상을 연결하는 부분을 이번 작업 주기에 설계·구현하려 한다고 설명했다. 양현석은 기존 문서의 책임 경계를 읽고 각 계층이 무엇을 맡는지 명확히 한 초안을 먼저 만들어 확인받으라고 답했다. 이 회의로 기존 API/계층 책임을 뒤집지 않는다. 화요일 회의 뒤 11시 제안과 수업·빠른 협의 요청이 있었지만 시각은 확정하지 않았다.

전투 UI·이동 편의의 상세는 양현석·이영빈이 별도로 다루는 후속이다. [00:32:42–00:32:56]

## 7. 일정·검증 상태

- 핵심 재미 검증이 지연됐고 Core 연동을 서둘러야 한다는 문제를 확인했다. 실제 통합 플레이·Build·M1/M2 완료 증거는 이번 작업에서 확인하지 않았다. [00:42:02–00:46:49]
- **팀원 5명 전원에게 크런치 모드를 도입하기로 결정했다.** 2026-11-01 황재동이 전원 도입 결정이 맞다고 확인했으므로 개인 계획/적용 대상 미확인으로 남겼던 해석을 정정한다. 대상은 황재동·양현석·조수빈·김진태·이영빈 전원이다. [00:58:56–01:04:04, 사용자 확인]
- 회의의 “17일까지 집중 작업”, “18–23일 휴식”은 전원 크런치 결정과 연결된 작업·휴식 계획으로 기록한다. 후반의 18–23일 표현을 우선하고, 구체 근무 시간·개인 불참·휴식 후 복귀일은 캘린더에서 조율한다. 전원 도입 결정 자체를 미정으로 되돌리지 않는다.
- 17일 무렵 재미 검증이 되겠다는 기대와 11월 내 전제 선택 목표는 승인된 Build 납기나 Gate 통과 판정이 아니다.
