## 요약

이 회의에서는 몬스터 개체마다 전장 전체를 평가하는 현재 구조의 계산량·밸런싱·확장성을 검토했다. **PoC에서는 기존 점수 기반 타깃 선택을 먼저 시험하는 방향으로 정리했다.** 스폰 시 고정 경로를 지정하는 안은 즉시 채택하지 않았다. 상위·분대·개체가 판단을 나누는 구조는 후속 설계 검토 제안이며, 계층 수·책임·클래스 구조와 PoC 적용 범위는 결정되지 않았다.

라이벌 플레이어 AI와 SOS 아군 플레이어 AI는 몬스터 개체 AI와 구분한다. 미래의 공통 기능·인터페이스를 논의했으나 라이벌 AI는 Deferred이며 이번 PoC 구현으로 추가하지 않았다. 기존 김진태·조수빈 소유 경계도 변경하지 않았다.

## 후속 확인

- 상위·그룹·개체 AI가 각각 맡을 판단과 명령, 평가 대상·범위·주기를 제안하고 기존 점수 기반 구현을 PoC에서 활용할 범위를 정리한다. 회의에서는 빠르게 공유하자는 요청이 있었으나 정확한 마감은 정해지지 않았다.
- 전선이 형성·유지되고 플레이어가 알아볼 수 있는지 터렛 배치, 사거리, 화력, 스폰 압력을 바꿔 관찰한다. 담당자는 회의에서 확정되지 않았다.
- 터렛 결과의 실제 병합·통합 상태와 다른 팀원의 이번 주 작업 공유 상태를 별도로 확인한다. 회의 발언만으로 완료를 표시하지 않는다.
- 아군·라이벌 플레이어 AI의 공통 기능과 인터페이스를 몬스터 개체 AI와 분리해 검토한다. 구체 Owner·일정은 확정하지 않았다.
