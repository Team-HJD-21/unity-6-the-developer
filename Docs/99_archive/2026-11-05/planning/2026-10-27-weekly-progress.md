기준일: 2026-10-27
상태: 회의 보고·우선 설계 방향·후속 목표 기록. 구현·게임 검증 완료 판정 아님

원본: 공유 드라이브 `The-Developer-V2/회의록/2026-10-27_주간_진행상황_보고`의 회의 요약 및 화자별 시간표시 전사. 자동 전사 기반이며 직접 청취 검수는 하지 않았다. 참석자는 황재동·양현석·조수빈·김진태이며 이영빈은 불참이다.

## 우선 적용할 경계

- Player 등 호출 파트의 터렛 조작 요청은 Core/Match가 권한·매치 진행 상태 등을 검증한 뒤 Turret API로 전달하는 방향을 먼저 설계한다. 다른 모듈에도 공통 방향으로 삼되 문제 시 조정한다. 조회 API 전체의 이동이나 상태 최종 권한·검증 항목·실패 응답·동기화 계약 전체를 확정한 것은 아니다. [06:48–11:14]
- Enemy는 게임 로직 두 벌을 복제하지 않고 실행 로직과 네트워크 결과 전달 계층을 분리하는 재구조화를 진행한다. Controller 내부 책임을 클래스로 나누고 변경 API를 다른 파트에 공유한다. 현재 방식으로 진행하되 팩토리·풀링 채택은 미정이다. [11:18–12:52, 14:39–21:14]
- 양현석의 Network 작업은 Authority·데이터베이스 등 기반 책임이다. 개별 객체의 위치·상태 동기화를 모두 대신하는 것은 아니며 각 기능 파트가 NGO 연결을 담당하는 경계와 구분한다. 온라인 전용·오프라인 개발·SOS 정책은 새로 확정하지 않았다. [17:28–18:27, 20:19–21:14]

황재동은 수리 API 추가·일부 Repair→TryRepair 명칭 정리·터렛 명칭 통일의 병합을 보고했다. 별도로 확인한 main `beea8f0d`의 PR #547은 FieldTurret 명칭·지속 수리·미사일 예약과 테스트 UI 변경을 포함한다. 회의 중 보고와 main 확인, 문서에 기록된 로컬 테스트와 실제 Stage 인수는 구분한다. 이번 문서 갱신에서 Unity나 다중 클라이언트를 실행하지 않았다.

## 제안·미결정

- 상태 권한 주체와 서버 Source of Truth, Core 요청 검증 계약·실패 처리 및 다른 모듈 적용 세부.
- Enemy 결과 전달 구조·NetworkTransform 연동·생성 팩토리·풀링과 실제 통합 결과.
- 비활성 해금 터렛의 타깃 처리 검증, 파괴 시 전력 반환·예약 비율.
- 낮·밤 시간 관리의 구체 대체 API와 Weather 공통 관리 구조.
- 영역에 들어온 적·터렛·플레이어를 공격하는 야생동물과 이동에 영향을 주는 식물은 후보이며 채택·효과·수치·Weather 통합 여부 미정.
- 파티클 대신 셰이더를 활용하는 날씨 표현은 조사 계획이며 최종 방식 확정 아님.

기존 Sprint 1을 유지한다. 새로운 Sprint 번호·Milestone Gate 완료·제품 승패 규칙 변경으로 해석하지 않는다. 목요일 회식 언급을 근거로 별도 캘린더 약속을 만들지 않는다.
