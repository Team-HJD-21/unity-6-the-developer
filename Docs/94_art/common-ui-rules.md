# 공통 UI 규칙 — HUD v6

기준일: 2026-11-13. 승인 HUD v6와 확장 공통 화면에 후속 UI 리뷰를 반영했다. 사용자가 HUD·공통 화면·Main·Credits의 1차 작업을 통과 처리하고 main 병합을 요청했다. 최초 적용은 [검증 기록](ui-validation-2026-11-12.md), 후속 수정은 [리뷰](ui-review-2026-11-13.md), 이번 전달 범위와 검증 한계는 [1차 마감 기록](ui-phase1-release-2026-11-13.md)을 따른다.

무기 오른쪽 탄창·재장전 통합과 최대 크기의 실제 간격은 [탄창 패널 리뷰](ui-ammo-dock-review-2026-11-13.md)에 기록한다.

이 문서는 승인한 전투 HUD를 기준으로 이후 Panel, Button, Tooltip에 재사용할 시각·조작 규칙을 정리한다. 세부 실행 시간과 가독성은 실제 화면 검증으로 조정하며, 디자인 승인과 게임 기능 검증을 구분한다.

## 시각과 에셋

- 얇은 무광 흑연색 바탕, 작은 모서리 절개와 한 겹의 밝은 선을 사용한다. 강한 네온·두꺼운 장갑·광택·장식 회로를 추가하지 않는다.
- 상태 기본 글자는 따뜻한 밝은색, 조작 강조는 절제된 금색이다. HP는 붉은색, 전력은 누런색이며, 종류와 상태를 색만으로 전달하지 않는다.
- 소유자는 같은 규격의 헬멧과 CU 4방향 릴레이 실루엣으로 구분한다. 상시 `Player`, `CU` 문구와 초상화·레벨 패널을 중복하지 않는다. 레벨·세부 상태는 기존 I 화면을 사용한다.
- 메인 로고의 Gravity 계열은 짧은 영문·키·수치에, 긴 한글 설명은 NEXON에 사용한다. `점유`는 실제 한글 글리프가 있는 `Mulmaru SDF` 텍스트다. 이전 이미지 레터링은 비활성 상태로 보존한다. 시간·점유율·수량·설명도 동적 텍스트다.
- 무기·스킬은 기존 게임 원본을 재사용한다. 터렛은 기존 베이스와 헤드를 조합한다. UI용 Sprite rect는 투명 여백을 제외할 수 있으나 원본 PNG·기존 GUID·게임 Sprite는 보존한다.
- HP·전력·XP·고정 자물쇠·취소·재장전 등 상태는 작은 심볼로 표현한다. 탄약은 무기 오른쪽의 현재/최대 수량으로 표시한다. 장비의 종류를 전달할 때는 장비 외형을 사용한다.

실행 에셋과 조정값은 [`CombatHudStyle.asset`](../../Assets/Art/UI/HudV6/CombatHudStyle.asset), import 기준은 [`import-source.json`](../../Assets/Art/UI/HudV6/import-source.json)에 있다. 기존 공용 NEXON SDF의 작업 내용을 덮어쓰지 않도록 HUD 본문은 별도 SDF를 사용한다.

## 분할과 배치

- 기준 해상도는 1920×1080이며 CanvasScaler로 대응한다. 다른 화면 비율에서도 텍스트·스킬 그림·원형 비율과 입력 영역을 함께 확인한다.
- 사각 Panel/Button/Tooltip/슬롯/무기 프레임의 Nine-slice border는 **소스 픽셀**의 좌·하·우·상 값이다. 바탕과 상태 테두리를 분리한다.
- 반원은 독립 부채꼴 4개, 마스크, 레일, 안쪽 바탕으로 나눈다. 원형 파츠에 Nine-slice를 적용하지 않는다. 반원의 지름선은 화면 맨 아래에 붙인다.
- 반원 안쪽에는 스킬 그림·포켓·눈금·장식 허브를 넣지 않는다. 밑변 중앙에서 장착된 칸을 가리키는 가는 바늘 두 개를 두고, 몸체 안의 원형 배지에 정방향 Q/E를 넣는다. 두 배지는 서로 다른 반지름에 놓고 바늘보다 나중에 그려, 회전 교차 중에도 글자와 선이 겹치지 않게 한다.
- 무기는 좌측 하단에 선택한 한 장만 표시한다. 후보 무기 그림은 숨기고 옆의 작은 1~4 번호로 선택한다. 현재 번호만 크게 강조하며, 교체 때 카드의 짧은 회전은 유지한다. 번호 클릭은 Submit 포커스를 남기지 않아 WASD·SPACE 게임 입력과 충돌하지 않는다.
- 무기와 탄약은 가로로 넓힌 얇은 패널 하나로 묶는다. 무기 번호는 패널 바깥 왼쪽에 세로 정렬하고, 패널 안에는 총 그림과 오른쪽 현재/최대 탄약 수량을 둔다. 실탄 띠는 표시하지 않는다. 번호 열은 패널의 세로 중심에 맞추고 별도 바탕을 붙이지 않는다. 최대 HUD 110%에서도 반원의 왼쪽 경계와 간격을 남긴다. 탄약은 무기 패널의 크기 설정·등장·접힘을 함께 따른다.

## 표시와 조작

모든 화면에서 조작·상태 판단에 필요한 정보만 남긴다. 메뉴 사용법을 서술하는 문장, 중복 안내, 장식용 인디케이터와 구현 절차 설명을 넣지 않는다. 실제 스킬 설명·수치·행동 결과·필수 로딩 상태는 해당 결정을 돕는 범위에서만 표시한다.

전투 HUD는 로컬 actor의 `PlayerMatchPresence.Location`이 Field인 동안만 표시한다. 우주선 방문/허브에서는 상단·좌우 바·스킬·무기·탄약·XP 팝업·필드 디버그를 숨기며, 연결과 장착 상태는 유지한다. 위치 서비스가 없는 단독 Feature 씬은 기존 표시를 유지한다.

| 요소 | 규칙 |
| --- | --- |
| 상단 | 공용 원본의 Day/Night·남은 시간과 점유율. 화면 상단에 붙인 반투명 역 사다리꼴 배경으로 가독성을 확보한다. 임의 로컬 게임 타이머를 누적하지 않는다. 마지막 5~0초에는 타이머만 붉게 바꾸고 매 초 작게 확대 후 복귀한다. |
| 보스 | 실제 활성 대상·이름·HP 원본이 연결된 동안만 표시한다. 일반 적을 보스로 추정하지 않는다. |
| 효과 | 실제 활성 효과만 우측 상단에 표시한다. 없는 효과·남은 시간·쿨타임을 만들지 않는다. |
| Player 바 | 좌측 가장자리 HP. 기본 고정이며 자물쇠로 표시한다. 클릭하면 자동 표시, 재클릭하면 고정이다. |
| CU 바 | 우측 HP+전력이 한 그룹이다. 기본 고정·자물쇠이며 Player 그룹과 고정/자동 상태는 독립이다. |
| 바 수치 | 해당 바를 호버할 때만 정수 현재/최대값을 위에 표시한다. 고정 상태가 상시 숫자를 뜻하지 않는다. |
| 피격 | 같은 최대 HP에서 실제 HP가 감소할 때만 짧은 흔들림·밝기 변화·감소 잔상을 표시한다. 최초 연결·최대값 변경·전력 소모는 피격으로 표시하지 않는다. |
| 평상시 스킬 | 하단 Q/E/SPACE. SPACE는 교체하지 않는다. 쿨타임은 슬롯 전체 윤곽을 따라 Filled로 덮으며 실제 수량은 숫자로 구분한다. 실제 키 입력에는 짧은 눌림·복귀를 넣는다. |
| 선택창 | 하단 감지 영역 접근 때 기본 슬롯이 숨고 반원이 나타난다. 선택창의 고정 모드는 없다. |
| 선택 호버 | 드래그 전부터 스킬 설명을 표시한다. 원본 그림이 살짝 들리고 얇은 집기 패턴이 나타나 이동 가능성을 암시한다. 조작 설명 문장은 추가하지 않는다. 드래그가 시작되면 이 반응을 정리하고 디스크 아래 설명 하나만 유지한다. |
| 드래그 | 큰 플로피 디스크 베이스 위에 원본 스킬과 대상 키 배지를 조합한다. 하단 이탈만으로 취소하지 않는다. |
| 드롭 영역 | Q 왼쪽/E 오른쪽의 넓은 영역. 화면 중앙 x에서 최대이며 **가로 거리**로 끝까지 옅어지는 전역 Gradient다. 글자·포인터 주변의 국소 발광이 아니다. 표시와 판정 영역을 일치시킨다. |
| 드롭 예고 | 유효 대상은 넓은 영역 강조와 디스크의 Q/E 배지, 영역 밖은 금지 배지로 예고한다. 중복 밑줄·설명 문장을 추가하지 않는다. 예고를 성공으로 표시하지 않는다. |
| 장착 | 새 스킬은 대상 슬롯만 교체하고, 다른 슬롯에 이미 장착된 스킬은 Q/E를 교환한다. 중복 장착하지 않는다. 동일 슬롯은 상태를 바꾸지 않는다. |
| 성공/취소 | 실제 성공 뒤 디스크를 짧게 밝히고 소멸시킨 뒤 반원을 닫고 기본 슬롯으로 복귀한다. 취소는 기존 장착을 보존하고 예고를 정리한다. 실패 폭발을 추가하지 않는다. |
| 탄약 | 무기 패널 오른쪽 중앙에 현재 수량을 크게, 최대 수량을 작게 표시한다. 실탄/소모 실루엣은 사용하지 않는다. 실제 발사 성공에만 수량의 짧은 확대·밝기 변화·작은 반동을 준다. 재장전 중에는 수량 아래 작은 회전 화살표를 표시하고 완료하면 중앙 수량 표시로 복귀한다. 무기 교체·최초 연결·저장 복원에서 발사 효과를 만들지 않는다. 스패너는 무한 표식을 사용한다. |
| XP | 실제 획득 이벤트의 양을 플레이어 주변 World Space UI로 표시한다. 저장 복원을 획득으로 연출하지 않는다. |
| Esc | 기존 개인 메뉴와 별도 우측 디버그 패널. 공용 전장을 정지하지 않으며 UI 클릭이 사격/설치로 전달되지 않는다. |
| Alert | 배경·프레임·색상 선 없이 중앙 정렬 텍스트만 하단 스킬 바로 위에 표시한다. 기존 본문 폰트와 의미색, 얇은 어두운 외곽선으로 가독성을 확보한다. 반원·설명·드래그 디스크의 실제 사각형과 겹칠 때만 위로 피한다. 같은 의미의 반복 입력은 표시 시간을 연장하지 않는다. 미배정 스킬 입력·실제 설치 확정 실패·터렛/CU 명령 결과가 대상이며 지속 상태는 해당 패널에 둔다. [송출 API와 수명](../02_architecture/03_scene-flow/common-alert-api.md)을 따른다. |

## 전환과 피드백

등장·숨김에는 구간 끝점을 정규화한 Sigmoid를 사용한다. 전환 도중 반대 요청이 오면 현재 위치·알파에서 이어가며 이전 완료 처리가 새 상태를 덮지 않는다.

```text
s(t) = 1 / (1 + exp(-k × (t − 0.5)))
e(t) = (s(t) − s(0)) / (s(1) − s(0)),  t ∈ [0,1]
```

무기 교체는 선택 카드 한 장의 짧은 이동·회전으로 표시한다. 탄약 소모의 작은 흔들림, 얇은 두 곡선 화살표의 재장전 회전, 자물쇠·호버·장착 성공은 각 의미를 구분한다. 초 카운트다운이나 과한 발광으로 상태를 중복하지 않는다. SPACE는 기존 `PlayerDashAfterimageIcon` 원본을 사용한다.

무기 이름은 카드 바로 아래의 기존 얇은 Panel 프레임으로 표시한다. 교체 후 약 1.4초 유지하고, 무기 또는 옆 번호를 호버하면 해당 이름을 유지한다. 이 이름의 등장·퇴장은 사용자 요청에 따라 0.18초 `smoothstep`을 사용한다. 처음 actor가 연결됐다는 이유로 교체 알림을 만들지 않는다.

필드의 명확한 공격 문맥에는 기존 `target_a` 픽셀 조준선을 사용한다. UI 주변·상단 정보·무기명·메뉴와 메뉴 퇴장 페이드·스킬 선택/설치·우주선·창 이탈에서는 일반 포인터를 유지한다. 커서 Canvas와 그림은 raycast하지 않으며 HUD 크기 설정과 독립인 32px로 표시한다. 실제 발사 성공에만 약 0.16초의 작은 확장·금색 반응을 주고 복귀한다. 클릭 자체를 발사 성공으로 연출하지 않는다. [실제 입력 검수와 도구 제한](ui-pointer-review-2026-11-13.md)을 구분해 읽는다.

첫 필드 HUD 표시는 약 0.6초 수평 스캔으로 드러낸다. UGUI stencil 셰이더를 사용하며 TMP·이미지에 같은 경계를 적용한다. 완료하면 스캔·마스크를 끄고 우주선 왕복으로 반복하지 않는다. 게임 시간·입력 lease를 바꾸지 않는다. 메인 버튼은 기존 Logo Show/Hide 이후 Up/Down 상태가 된 뒤 약 0.4초 등장하며, 키보드/호버는 글자색으로만 강조한다. 버튼 사이 중심 간격은 110px, 글자 크기는 동일하며 원래 Version Label을 유지한다.

포탑의 Activate/Deactivate 의미색은 초록/빨강을 유지한다. 공통 호버 코드가 이 글자를 흰색으로 덮지 않으며 테두리로 반응한다. 정상 상태의 중복 표시·상시 분기 선택 안내·만피 수리 프롬프트는 숨긴다. 실제 제한·냉각·실행 결과는 필요한 동안 표시한다. 레벨 화살표와 +/−는 가독성과 클릭 간격을 함께 확인한다.

현재 Style의 전환 시간·숨김 유지시간·강도는 Inspector에서 조정한다. 실제 입력 뒤 Game View 연속 캡처로 반원 전환, 장착 확인 fade, 무기 카드 회전·알파, 재장전 회전과 XP 표시를 확인했다. 새로운 값을 적용하면 같은 방식으로 다시 확인한다.

## 데이터와 입력 경계

- 기존 Scene 소유 HUD의 로컬 actor binding을 유지한다. 원격 Player나 다른 Scene actor를 임의로 선택하지 않는다.
- CU는 정식 Match의 Host 확정 presentation을 읽는다. UI가 자체 전력·성공 상태를 만들거나 권한 검사를 우회하지 않는다.
- CU 자동 활성화 디버그는 **현재 메뉴 id만 정상적으로 닫아 그 메뉴의 input lease를 해제한 뒤**, 기존 HUD 요청 경로를 호출한다. 다른 생존/전환 잠금은 보존하며 응답 전에 메뉴를 자동으로 다시 열지 않는다.
- 2026-11-12 현재 점유 가능 영역의 확정 분모와 보스 marker/presentation source가 없다. 최종 점유율은 `--%`, 보스 UI는 숨김으로 둔다. 전체 Grid 셀 비율을 완성된 점유율로 대체하지 않는다.
- 현재 감속 API는 실제 배율과 활성 효과 수를 제공한다. 공개되지 않은 효과별 ID·남은 시간을 꾸며 표시하지 않는다.

실행 검증은 별도 기록으로 남긴다. 정적 에셋 검사, 자동 테스트, 실제 Scene 플레이, 직접 수동 입력과 애니메이션 관찰은 서로 대체하지 않는다.

## 해상도와 크기 설정

HUD와 공통 화면의 CanvasScaler는 1920×1080 기준 `Scale With Screen Size / Expand`다. 화면 끝 anchor와 원형 비율을 유지하고, 화면 전체 Q/E 드롭 영역은 전역 화면 비율로 판정한다.

설정창의 **전투 HUD 크기**는 기본 85%, 범위 75~110%다. 무기·반원·컴팩트 슬롯·바·탄약과 해당 입력 영역을 함께 조절한다. 상단 정보는 최소 85%, 설명은 최소 90%를 유지한다. 전체 Canvas를 축소해 화면 판정까지 줄이지 않는다. `CombatHudScaleBinding.Elements`에서 대상·기준 오프셋·최소 배율을 편집한다.

슬라이더는 즉시 미리보기를 제공한다. 적용은 로컬 `PlayerPrefs`의 `CBC.UI.HudScale`에 저장하고, 취소·Escape는 창을 열기 전 값으로 복원한다. 기본값 버튼도 적용 전까지는 미리보기다. Match 저장 형식이나 게임 판정에는 영향을 주지 않는다.

설정창 아래에는 **전체·음악·효과음** 음량을 같은 슬라이더 규칙으로 배치한다. 범위는 0~100%, 기본값은 100%다. 즉시 미리듣고 적용 때만 저장하며 취소·Escape는 열기 전 음량으로 복원한다. 레이블·수치·기본값/취소/적용 외의 반복 안내 문장은 추가하지 않는다. [오디오 출력·에셋 규칙](../02_architecture/01_core/game-audio-api.md)을 따른다.

## 공통 화면과 Editor 편집

`Assets/Prefabs/UI/Common`의 프리팹을 직접 편집한다. 실행 중에는 제작된 프리팹을 인스턴스화하고 Inspector에 연결한 참조를 사용한다.

| 프리팹 | 편집 대상 |
| --- | --- |
| `AppScreenCanvas` | 운영 화면 정렬, Screen Stack, 전체 화면 암전 |
| `CommonButton` / `MenuTextButton` | 공통 버튼과 메인 텍스트 버튼, Hover·선택 피드백 |
| `MenuScreen` / `ResultScreen` | 개인 메뉴와 실제 결과·재시작/복귀 |
| `SettingsScreen` | HUD 크기·배율 미리보기, 전체/음악/효과음 음량, 기본값/취소/적용 |
| `LoadingScreen` | 조작 정보, 실제 진행률 또는 수치 없는 이동 막대 |
| `StartupControls` | 메인 시작/설정/종료 버튼 |

`Assets/Resources/Core/AppScreenStyle.asset`가 이 프리팹들을 연결한다. 메인의 기존 Canvas, 배경 이미지, 로고·폰트·배치를 보존하고 새 버튼은 별도 Canvas에 둔다. 개인 메뉴는 필드와 우주선 모두에서 동작한다. 상태창·스킬 트리·포탑 패널도 동일한 얇은 프레임·본문 폰트·Hover 규칙을 사용하며 기존 기능 참조는 유지한다.

개인 메뉴의 우주선 복귀는 실제 이동 가능한 게임 흐름에서만 표시한다. 메인·독립 허브에서는 계속하기/설정만 남기고 패널 높이와 키보드 순환도 함께 줄인다. 설정 등으로 가려진 메뉴는 마지막 선택을 기억하며, 메뉴를 닫으면 이전 화면의 유효한 선택을 복원한다.

Filled 게이지의 `fill_white_solid.asset`는 원본 흰색 텍스처의 불투명 중심만 참조하는 Sprite다. 투명한 가장자리를 게이지 전체에 늘려 100%가 짧아 보이게 하지 않는다. 원형 쿨타임에는 Filled 동작을 유지한다.

UI 화면 자체를 설명하는 문장, 닫기/스크롤 반복 안내, 미구현 재화의 빈 수치, 임시 버전 표기는 표시하지 않는다. 스킬의 실제 설명, 행동 결과와 조작 선택에 필요한 상태는 유지한다. 로딩의 조작 정보는 레거시 구성을 참고하되 현재 입력(Q/E 스킬, SPACE 대시)을 사용한다.

`Tools/TeamHJD/The Developer` 아래 제작 도구는 초기 계층 재생성용이다. 수동으로 다듬은 프리팹을 다시 생성하면 조정값이 제작 기본값으로 돌아갈 수 있으므로 일반 편집에 실행할 필요는 없다.
