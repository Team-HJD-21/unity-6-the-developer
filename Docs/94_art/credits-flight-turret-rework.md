# 비행·터렛 장면 재구성안

2026-11-13 사용자 요청에 따른 **분석과 수정 제안**이다. 아래의 새 시점 원화·기구 애니메이션은 아직 적용하지 않았다. 이번에 적용한 범위는 우주선의 짧은 후진 후 기존 시각 출발, 소행성 뒤의 슬라임 한 마리다.

## 고정할 타임라인

OST 제작 기준을 보존한다. 기존 파트 길이, Fade, 이름·역할 공개, 효과음 cue, 로고와 최종 명단 시각을 옮기지 않는다. 새 샷과 효과는 아래 구간 안에서 교체한다.

| 구간 | 전체 시각 | 고정할 사건 |
|---|---|---|
| 비행 | 9.5–19.5초 | 14초 가속·통과 효과음 시작, 15.55초 이름 공개 시작, 15.8초 역할 공개 시작 |
| 소행성 | 19.5–29.5초 | 22.95초 이름 Fade 시작, 25.6초 역할 공개 시작 |
| 터렛 | 29.5–39.5초 | 31.9 / 32.75 / 33.6초 착지, 35.5초 이름 Fade 시작, 35.8초 역할 공개 시작 |
| 이후 | 39.5초부터 | 드론 39.5–51초, 로고 51–55초, 정적 명단 55초부터 |

## 현재 화면에서 부족한 점

비행은 엔진 근접에서 전체 샷으로 이동하지만, 넓은 샷에서는 선체 한 장이 배경 위에 떠 있는 인상이 강하다. 엔진 불꽃과 작은 입자는 존재하나 노즐의 실제 힘과 기체 속도를 설명하기에는 약하다. 별 궤적도 일정한 방향·속도로 움직여 대기와 가속의 차이가 작다. 선체의 정적인 음영은 카메라가 움직여도 그대로라 금속과 두께가 잘 드러나지 않는다.

터렛은 탑다운 Sprite 세 장을 화면 위에서 아래로 옮기는 동작이 주가 된다. 이는 고도가 낮아지는 낙하보다 평면 위 이동으로 읽히기 쉽다. 그림자·먼지·반동이 있어도 기체 하부, 제동 장치, 지면과의 접촉을 설명하는 그림이 부족하다. 같은 크기와 방향의 세 터렛, 반복되는 지면, 착지 후 정지가 겹쳐 게임 배치 미리보기처럼 보인다. 이름 패널을 다시 붙여서는 이 문제가 해결되지 않는다.

## 비행 수정안

| 전체 시각 | 화면과 동작 |
|---|---|
| 9.5–11.7초 | 뒤쪽 엔진을 비스듬히 보는 근접 샷. 노즐 내부의 작고 밝은 코어, 금속 림의 반사, 엔진별로 조금 다른 점화 위상. 선체 전체를 흔들지 않고 노즐 주변만 짧게 진동한다. |
| 11.7–13.25초 | 측면 전체 샷으로 연결한다. 먼 성운·중간의 작은 돌·가까운 전경 조각에 서로 다른 이동량을 주어 카메라 이동을 읽게 한다. 전체 배경을 빠르게 밀지 않는다. |
| 13.25–14초 | 이번에 적용한 짧은 후진과 자세 잡기. 주 엔진은 작아지고, 동체는 무게감 있게 멈춘다. 방향 전환 노즐이 필요한 새 원화에는 해당 위치를 분리해 그린다. |
| 14–15.55초 | 기존 시각에 가속한다. 불꽃의 밝은 코어→짧은 배기→드문 잔류 입자를 별도 계층으로 연결한다. 배경과 전경의 상대 속도가 함께 바뀌고, 카메라는 살짝 늦게 따라가며 기체가 프레임을 빠져나가게 한다. 긴 네온 꼬리와 화면 전체 Bloom은 쓰지 않는다. |
| 15.55–19.5초 | 궤적이 걷히며 기존 이름이 같은 시각에 드러난다. 입자와 밝기가 빠르게 줄어 이름을 읽을 공간을 남긴다. 마지막을 새 동작으로 채워 글자를 방해하지 않는다. |

필요한 원화는 기존 우주선을 기준으로 한 **후방 3/4 엔진 근접용 원화**, 기존 측면과 연결되는 기체, 분리된 노즐/반사 마스크다. 측면 PNG를 찌그러뜨려 다른 시점처럼 만들지 않는다. 현재 선체의 청회색 패널·대각 금속 띠·청록 캐노피·작은 호박색 부품과 픽셀 밀도를 유지한다. 배기는 독립된 짧은 애니메이션과 입자로 제작한다.

## 터렛 수정안

| 전체 시각 | 화면과 동작 |
|---|---|
| 29.5–30.55초 | 가까운 기체 하부와 아래의 착지 지면을 함께 보여주는 3/4 샷. 지면은 제자리에 있고 기체와 그림자의 간격이 고도를 설명한다. 불필요한 목표 UI·패널을 얹지 않는다. |
| 30.55–31.9초 | 첫 기체 낙하. 하부 제동 노즐·접힌 지지대·작은 기체 흔들림을 분리한다. 그림자는 좁고 진해지고 지면 먼지는 접촉 직전에 옆으로 밀린다. |
| 31.9–33.6초 | 기존 세 착지 시각에 맞춰 탑다운 장면으로 이어간다. 접촉 순간의 지지대 압축과 짧은 지면 입자, 늦게 가라앉는 먼지로 무게를 보여준다. 기체는 즉시 멈추고 먼지만 계속 움직인다. 화면 흔들림은 짧고 작게 제한한다. |
| 33.6–35.5초 | 지지대 잠금→포탑 헤드 정렬 순서로 가동한다. 포신과 베이스를 분리해 기계 동작을 만든다. 두 번째와 세 번째 기체는 다른 위상·각도를 사용한다. 큰 섬광이나 UI 상태 표시를 넣지 않는다. |
| 35.5–39.5초 | 앞쪽 터렛 오른편에 기존 이름만 Fade-in. 이름은 Chapter에 고정하고 기체와 같이 떨어뜨리지 않는다. 먼지와 카메라 이동은 줄이고 짧은 헤드 정렬 잔동작만 남긴다. |

필요한 원화는 **낙하용 3/4 터렛과 하부**, 분리된 지지대·포신·베이스·제동 노즐, 작은 착지 파편, 게임 지면과 어울리는 넓은 착륙 구역이다. 기존 파란 터렛의 실루엣과 색을 유지한다. 생성 결과의 시점이 다른 부품을 조립하지 않으며, 흙먼지는 원형 스프라이트 확대 대신 낮은 분사·미세 입자·드문 파편으로 구분한다.

## 제작·검수 기준

- 먼저 동일 시각의 샷 보드로 구도와 실루엣을 확정한다. 개별 원화가 좋아 보여도 실제 배치 크기에서 어색하면 사용하지 않는다.
- 새 에셋 수에 임의의 제한을 두지 않는다. 필요한 시점은 새로 제작하되, 그림체·광원·픽셀 밀도·윤곽선·팔레트 기준을 같은 참조에 고정한다.
- 반사·배기·지지대·먼지·그림자는 독립 계층으로 만들어 카메라 및 동작과 연동한다. 글자를 원화에 합성하지 않는다.
- 0.25초 간격 정지 화면과 정상 속도 재생을 함께 확인한다. 착지 전후에는 더 촘촘하게 확인해 미끄러짐, 부품 분리, 지면 관통, 효과 발생 위치를 찾는다.
- 이름이 보이는 구간의 피사체·밝은 효과·전경과의 관계를 실제 렌더에서 확인한다. 원래 이름 공개 효과 이외에 새 효과가 글자를 덮지 않게 한다.
- 파트별 시작/종료, 이름·역할·효과음 cue, 로고 51초, 최종 명단 55초를 변경 전후 데이터와 실제 재생으로 대조한다. 시각 품질 개선을 이유로 길이를 늘리지 않는다.
