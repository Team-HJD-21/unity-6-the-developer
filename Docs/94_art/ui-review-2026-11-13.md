## 검증 범위

- 원래 배경/로고/로고 Animator와 사용자 NEXON SDF 변경을 보존했다. pull 전후 수정 파일 해시를 대조했고 겹치는 기능 코드는 없었다. 날씨 파일은 실제 내용이 동일한 LF/CRLF 차이만 Git이 기대하는 형태로 맞춘 뒤 pull했다. reset/stash/브랜치 전환·추가 커밋/푸시는 하지 않았다.
- 실제 Main: 첫 로고 구간 버튼 alpha 0, 약 2.85초에 .96, 약 3.28초에 alpha 1/입력 가능. Version·새 간격·Hover를 Game View에서 관찰했다.
- 실제 필드: 양쪽 기본 고정·자물쇠, 몰마루 `점유`, 잔상, 선택 무기 한 장·옆 번호를 확인했다. 실제 번호 클릭으로 Sniper를 선택했고 다른 카드 alpha는 모두 0이었다. 정상 프레임에서 2.3/4.6/4.8/2.4도 회전을 관찰했다.
- 실제 사격 5→4, R 재장전 뒤 5. 44개 연속 프레임 중 30개가 실제 재장전 구간이었고 새 화살표 회전을 확인했다.
- 월드의 실제 포탑 클릭으로 패널을 열고 실제 Activate/Deactivate 버튼을 클릭했다. 초록/빨강이 Hover 중에도 유지되고 선택 클릭·UI 클릭으로 탄약이 소모되지 않았다. 자동 검사에서도 hover 8프레임·이탈 4프레임에 의미색을 대조했다.
- 실제 우주선에서 HUD 숨김·메뉴, 정상 출구에서 첫 HUD 스캔을 확인했다. 두 HUD의 진행도는 .01→.95가 같은 약 0.56초 구간에 기록됐고 완료 후 마스크가 꺼졌다.
- 추가 우주선 왕복에서도 같은 actor와 Q=Bomb/E=PlayerTurret 장착을 유지했다. 내부에서는 Canvas와 양쪽 바가 숨겨지고, 복귀 후 두 HUD 모두 완료 상태·진행도 1·마스크 비활성을 유지했다. 정상 프레임 연속 기록에서도 등장 연출이 반복되지 않았다.
- 자동 검사 61개: 프리팹 14, 설정 6, HUD 표시/입력 2, 무기 2, 수리 35, 포탑 Host 버튼/메뉴/의미색 2. 무기 번호의 마지막 포커스 수정 후 관련 HUD 표시 2개도 다시 통과했다.
- 최종 에셋 검사에서 새 `.meta` 누락·GUID 중복·대상 프리팹 Missing Script는 0이었다. 원래 메인 배경/로고의 직렬화 블록과 NEXON 파일 해시를 보존했다. HUD 셰이더는 Editor DX11에서 지원되며 컴파일 메시지가 없었다. YAML 정리는 fileID별 의미를 보존했고 `git diff --check`를 통과했다.

실제 입력은 가상 Mouse/Keyboard를 정상 Input System 프레임에 전달하는 방식이며 UI click/equip 핸들러 직접 호출과 구분했다. 포탑 가까이 이동·GameFlow/우주선 출구 API는 검수 상태 준비에 사용했다. 긴 조작 관찰 때만 런타임 검수 세션의 적 예약을 중지했으며 제품 Scene에 저장하지 않았다.

실제 Game View 캡처와 이전 시안의 비교본, 모션 원본 PNG/JSON은 로컬 검수 아티팩트로 제공한다. 시안의 예시 점유율·기존 무기 스택과 현재 실제 수치·사용자 수정안을 같은 것으로 표시하지 않는다. Prototype Scene의 배경 도형은 원래 Scene 데이터다.

비교본은 HUD/메인/설정/퍼즈/로딩의 다섯 화면과 터렛 변경 전후를 제공한다. HUD의 반원·바늘·드래그 전 호버 설명, 우주선 메뉴는 추가 상태로 분리했다. 실제 연속 프레임을 포맷 변환한 GIF는 메인 등장 95프레임, HUD 스캔 59프레임, 무기 교체 17프레임, 재장전 44프레임이며 생성·보간 이미지를 사용하지 않았다.

검수 후 Unity는 Startup 편집 모드·Scene 수정 없음·원래 Game View 크기 0으로 복원했다. 검수 입력장치를 제거했고 원래 HUD 설정 키 부재를 확인했다. 런타임 날씨 값은 pull 이후 기준으로 돌렸으며, 부수적으로 저장된 ThinMulmaru 글리프 캐시와 TimeManager 직렬화 변환은 제거했다.

Standalone·물리 OS 입력·원격 Client/공동 씬 이동은 이번 리뷰에서 새로 인수하지 않았다. 점유 분모/보스 원본 부재 등의 기존 제한은 [최초 검증 기록](ui-validation-2026-11-12.md)을 따른다.
