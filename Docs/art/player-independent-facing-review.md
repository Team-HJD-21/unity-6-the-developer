# 플레이어 독립 좌우 자세와 제트팩 분사구

담당: 이영빈 · 2026-10-30 · PR #575 후속.

좌우 자세를 각각의 원본으로 연결하고, 불꽃이 가방 하단 분사구에서 시작하도록 그림을 수정했다. 초기 좌우 반전 공유 방식은 이번 독립 방향 연결로 교체한다.

## 반영 범위

- 좌측 클립 38개를 해당 방향 원본과 `flipX=0`으로 연결했다. 그중 대각선 대기 4개는 새 좌측 프레임 16장을 사용하며 기존 0.8초 호흡 루프를 유지한다.
- 새 좌측 프레임에는 기존 같은 방향의 손·분리 무기·정렬·총구 설정을 연결했다. Appearance 항목 32개를 추가하고, 반전 전제로 바뀌었던 총구 좌표 10개를 원래 방향별 값으로 되돌렸다.
- 불꽃이 있는 이동·이동 공격·수리·후진 몸체 124장을 수정했다. 새 좌측 대기까지 합쳐 이번에 제작·등록한 런타임 PNG는 140장이다.

## 분사구 기준

등 뒤 사각 가방의 **양쪽 아래 모서리**에 작은 회색 분사구를 두고, 그 끝에서 불꽃이 바로 이어지게 한다. 중앙의 검은 장식이나 허벅지·팔 아래를 배출구로 삼지 않는다. 두 불꽃은 몸통·가방의 기울기에 따라 같은 방향으로 기울며, 원근에 따라 반대쪽 불꽃 일부가 가려질 수 있다.

뒤를 보는 자세는 가방이 몸보다 카메라에 가까우므로 분사구와 불꽃이 허벅지 바깥쪽을 덮을 수 있다. 불꽃을 다리와 겹치지 않게 하려고 가방 바깥으로 옮겼던 초기 시안은 사용하지 않는다. 기울임 두 자세도 가방 하단 모서리 위치를 따로 확인했다.

## 에셋과 출처

- 몸체: `Assets/Art/Sprites/Player/Motions/V2/` 아래 기존 자세별 폴더.
- 새 좌측 대기: `Assets/Art/Sprites/Player/Motions/V2/DiagonalIdle/*Left_0..3.png`.
- 생성 원본: `Assets/Art/Sprites/Player/Motions/V2/Source/IndependentFacing_*_Source.png`.
- [현재 몸체·무기 조합 미리보기](player-independent-facing-preview.gif).
- [프레임·원본 해시·생성 요청·등록 기록](player-independent-facing-review.json).

같은 자세가 여러 원본 시트에 있으면 프레임 기록의 `group`이 최종 등록에 사용한 원본을 가리킨다. 실제 런타임은 자세별로 분할한 PNG를 참조한다.

실제 그림은 내장 `image_gen`으로 편집했다(`art_source: host_image`). 좌우를 각각 기존 방향의 그림에서 수정하고, 완성 그림을 고정 격자로 분할·축소·등록했다. 두 기울임 프레임은 동일 배율과 기존 머리 기준점으로 전체 그림을 등록했다. 색상으로 다리나 불꽃을 추정해 지우거나 신체 부분을 재조립하지 않았다. 기존 몸체와 클립의 GUID는 유지한다.

## 검증과 남은 확인

140장 모두 160×160, Alpha 0/255, 32 PPU, Point 필터와 이미지 가장자리 여백을 확인했다. 독립 좌측 클립 38개, 대각선 대기 프레임, Appearance 참조, 총구 좌표와 기존 메타 보존 검사를 통과했다. 몸체와 분리 무기를 합성한 방향별 미리보기를 확인했다.

Editor 프로젝트 컴파일은 오류 0개다. 기존 다른 담당 영역 경고 5개는 남아 있다. Unity Test Runner와 실제 플레이는 수행하지 않았으므로, 에디터에서 좌우·대각선 이동, 후진 공격 시 손과 총구, 불꽃의 겹침과 전환을 최종 확인해야 한다. 이미지의 시각 검토와 실행 검증은 구분한다.
