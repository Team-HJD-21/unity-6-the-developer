# 오른손 자세와 무기 연결 검토

담당: 이영빈 · 2026-11-01

## 변경 이유

기존에는 몸체마다 추출한 작은 무기 조각을 사용했다. 같은 스나이퍼도 좌상·우상 대기의 총열·스코프 비율이 달랐고, 대기에서 이동으로 바뀌면 총 자체의 길이까지 변했다. 일부 조각에는 손·다리처럼 보이는 주변 픽셀이 남았다. 좌상단 스패너는 준비 자세와 타격 자세에서 무기를 잡는 팔이 바뀌어 보였다.

## 현재 연결

- 총기 3종은 각각 독립 8방향의 완성 무기 그림을 공유한다. 위치 기준은 무기 중심이 아니라 실제 오른손과 손잡이의 접촉점이다.
- 총기 몸체 108개 × 무기 3종의 324개 연결을 새 그림으로 교체했다. 같은 방향에서 대기·이동·사격·기울임·후진으로 바뀌어도 무기의 형태와 크기는 같다.
- 대기 호흡은 손잡이 위치와 각도를 고정한다. 총은 오른손으로 방아쇠를 잡고 왼손으로 앞부분을 받친다. 오른손을 화면 오른쪽으로 해석하지 않는다.
- 일반 총구와 실제 사격 클립 0초의 총구를 각각 계산했다. 대각선 사격이 옛 단일 대기 몸체를 첫 프레임으로 사용한다는 점도 반영했다.
- 몸체 PNG GUID, 160×160 캔버스, 32 PPU, 클립 키와 재생 길이는 유지한다. 좌우 몸체를 반전으로 대체하지 않는다.

## 편집할 파일

- `Assets/Data/Player/Weapons/*Appearance.asset`: 몸체별 부착 위치·각도·총구.
- `Assets/Art/Sprites/Player/Motions/V2/SeparatedWeapons/Canonical/`: 현재 사용하는 무기 그림.
- `Assets/Art/Sprites/Player/Motions/V2/Source/RightHanded_*`: 내장 이미지 생성 도구의 제작 원본.
- `Assets/Art/Sprites/Player/Motions/V2/Idle/`, `DiagonalIdle/`, `ToolIdle/`와 해당 동작 폴더: 팔·손이 포함된 몸체 그림.

구조와 유지보수 기준은 [무기 외형 API](../architecture/player-weapon-appearance-api.md)에 정리했다. 생성된 그림을 잘라 등록하고 기존 헬멧·하체와 맞춘다. 코드로 새 팔이나 무기 윤곽을 그리지 않는다.

## 이미지 생성 사양

내장 `image_gen`의 이미지 편집을 사용했다. API 키·영상·Grok은 사용하지 않았다. 아래는 작업별 최종 프롬프트 사양이다.

1. **총기 원본 3장:** 기존 오른쪽 무기를 디자인 기준으로 삼아 같은 총의 8방향 전체를 제작. 순서는 Down, DownLeft, Left, UpLeft / Up, UpRight, Right, DownRight. 총몸·개머리판·총열·스코프 비율 유지. 흰색·차콜 계열, 냉각총만 작은 청록 냉각부. 손·몸체·이펙트·문자 없는 투명 배경. 좌우 별도 시점으로 제작.
2. **대기 4장:** 방향 4행 × 호흡 4열. 팔과 장갑의 오른손 기준 연결을 교정하고 기존 무기 잔여를 제거. 헬멧·복장·가방·다리·부츠 보존. 총은 오른손이 뒤쪽 방아쇠, 왼손이 앞쪽 지지. 스패너는 오른손 주사용, 왼손 비무장. 호흡 중 손 위치 고정.
3. **스패너 동작 4장:** 좌우·후면·좌상단의 공격/수리 준비·타격·회복에서 같은 오른쪽 어깨부터 팔꿈치·손목까지 연결. 공구 조각이 없는 닫힌 장갑으로 제작. 기존 몸체 기울기·가방·다리·분사 불꽃 유지.
4. **좌상단 재교정:** 오른쪽 어깨에서 이어지는 주먹을 가방의 화면 오른쪽에 분명히 표시. 준비→타격→회복에서 같은 팔 유지. 화면 왼쪽의 팔은 공구를 들지 않는 보조 팔. 좌측 측면은 먼 쪽 오른팔에서 앞으로 이어지는 손을 사용.
5. **스패너 원본:** 흰색·차콜 외곽의 완전한 세로 렌치 한 개. 위쪽 열린 턱, 긴 손잡이, 아래쪽 작은 원형 구멍. 장갑·몸체·문자·이펙트 없는 투명 배경.

## 검증 경계

총기 324개 합성 화면을 전체 검토했다. 오른손 부착점·현재 총구·실제 사격 첫 프레임 총구는 작성 좌표와 일치하고, 비어 있는 무기나 이전 조각 참조는 없다. 스나이퍼 좌상·우상 대기의 같은 무기 비율을 비교했다. 이 수치는 의도한 좌표와 에셋 연결의 검증이며 해부학적 판단 자체를 수치로 증명하는 것은 아니다.

Editor 테스트에 방향별 동일 무기 사용, 대기 부착점 고정, 총기 3종의 모든 사격 첫 총구 검사를 추가했다. `dotnet` 컴파일은 오류 0개. Unity Test Runner와 실제 플레이 확인은 실행하지 않았다. Unity의 재임포트 후 8방향 대기·이동·연속 사격·스패너 공격·수리를 확인해야 한다.

세부 원본 해시·접촉점·전체 합성 보드·수정 전 백업은 로컬 작업 기록 `Docs/Local/PlayerRightHanded20261101/`에 보관한다. 이 디렉터리는 로컬 검토용이며 Git 추적 대상이 아니다.
