# 플레이어 스프라이트 전체 확인 — 2026-10-23

현재 Player V2의 원본 생성 파일을 제외한 PNG 263장을 전부 확인했다. 대기, 이동, 정지 사격, 이동 사격, 스패너 공격, 수리, 후진 자세와 탄환·총구·피격 FX를 포함한다. 클립에서 참조하는 PNG는 204장이다. 미사용 자세 변형도 확인 범위에 포함했다.

- 기존 불꽃이 섞여 있거나 일부 방향에서 빠졌던 146장을 수정했다. 사용하지 않는 이동 자세 변형도 함께 정리했다.
- 기준은 승인된 대각선 이동의 작고 부드러운 흰색 제트팩 불꽃이다. 기존 청록색 가장자리와 뾰족한 형태를 줄이고 중립적인 흰색·회색으로 맞췄다.
- 좌우 후진 자세의 두 분사 방향을 제트팩 아래에서 다리가 뻗는 방향으로 맞췄다. 발에는 별도 불꽃을 붙이지 않았다.
- 승인된 대각선 이동·후진 8장을 포함한 나머지 117장은 파일 해시가 동일하다. 정지 대각선 사격의 반동·복귀 프레임도 유지했다.
- 기존 PNG GUID, 캔버스 크기, PPU, 피벗, 애니메이션 키와 연결은 유지했다. 런타임 코드, 총구 앵커, 콜라이더를 변경하지 않았다.
- 이미지 생성은 내장 `image_gen` 편집으로 자세별로 진행했다. 후처리는 프레임 분리, 위치·크기 정렬, 원래 몸 윤곽 보호, 팔레트·알파 정리에 사용했다. 얼굴과 헬멧의 보이는 픽셀을 보존했고, 하단에 남은 옛 청록색 가장자리는 중립색으로 정리했다.

[전체 263장 전후 비교](player-sprite-audit.html)에서 폴더·수정 여부·클립 사용 여부로 필터링할 수 있다. [대표 자세 전후 비교](player-exhaust-consistency-preview.png)와 [생성 프롬프트·원본·해시·검사 기록](player-exhaust-consistency.json)도 함께 제공한다.

PNG 크기·투명도, 얼굴 픽셀, 기존 메타 보존, 수정하지 않은 파일 해시는 검사했다. Unity 플레이 화면에서의 전환과 실제 배경 위 가독성은 아직 확인하지 않았다.
