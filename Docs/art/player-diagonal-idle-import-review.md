# 대각선 대기 무기 연결 임포트 수정

담당: 이영빈 · 2026-10-31.

대각선 대기 그림은 파일에 연결돼 있었지만 Unity가 실제로 읽은 Appearance 배열에는 없었습니다. 임시 Editor 진단에서 총기 3종은 파일의 108항목 중 92항목, 스패너는 168항목 중 152항목만 읽었고 대각선 대기 연결 64개가 전부 누락됐습니다. 따라서 이전의 파일 문자열 검사만으로는 실행 상태를 확인할 수 없었습니다.

Appearance 파일 4개에서 배열 항목 사이 빈 줄 16개씩을 제거했습니다. 모든 설정값·Sprite 참조·항목 순서는 그대로 보존했습니다. 다시 임포트한 Unity Editor에서 총기는 각각 108항목, 스패너는 168항목을 읽고 실제 대각선 Sprite 64개를 무기 프레임으로 모두 조회하는 것을 확인했습니다. 이 수정에는 런타임 캐시 우회나 이름 기반 대체 연결을 추가하지 않았습니다.

`PlayerWeaponAppearanceTests.ImportedFrameCountMatchesAllAuthoredWeaponEntries`는 실제 Unity 배열 개수를 파일의 작성 항목 수와 비교합니다. 기존 실제 몸체 모션의 무기 연결·알파 검사와 함께 이와 같은 조용한 뒤쪽 항목 누락을 검사합니다.

[임포트 전·후 수치와 설정값 보존 기록](player-diagonal-idle-import-review.json).

Editor 프로젝트 컴파일은 오류·경고 0개입니다. Unity 네이티브 임포트와 64개 조회를 검증했으며 Test Runner나 실제 플레이 화면을 자동 실행한 것은 아닙니다. 임시 진단 C#과 메타는 확인 후 제거하고 진단 원본·결과는 Docs/Local에 보관합니다.
