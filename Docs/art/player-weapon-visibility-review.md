# 플레이어 8방향 무기 표시 복구

담당: 이영빈 · 2026-10-31.

실제 플레이 모션 104개, 몸체 276개, Appearance 492항목을 검사했습니다. 무기 GUID와 프레임 연결은 있었지만, 위쪽 이동 총기 12장과 위쪽 스패너 준비 동작 2장이 완전히 투명한 PNG를 참조했습니다. 위쪽 대기 총기 12장은 총 끝부분만 작게 남아 있었습니다.

4개의 무기 Appearance에서 총 26항목을 수정했습니다. 같은 무기·같은 방향의 정상 사격 그림을 대기·이동의 손 위치에 맞춰 재사용하고, 빈 스패너 준비 그림은 기존 대기·이동 공구 그림으로 연결했습니다. 기존 몸체·불꽃·무기 PNG와 애니메이션은 편집하지 않았습니다.

내려 잡은 총의 일반 총구는 무기 위치와 같은 차이만큼 이동합니다. 첫 발용 총구는 사격 모션의 첫 프레임 위치를 사용합니다. 냉각총·스나이퍼의 빈 이동 프레임에 꺼져 있던 총구 Override를 켜서 기본총 총구 좌표를 대신 사용하던 연결도 교정했습니다.

원거리 무기와 스패너를 바꾼 같은 프레임에 이전 몸체 자세가 새 Appearance와 맞지 않아 잠깐 숨는 문제도 수정했습니다. 계열을 바꿀 때 현재 이동 상태에 맞는 몸체 자세를 즉시 평가하며, 같은 원거리 계열의 교체는 모션을 재시작하지 않습니다.
