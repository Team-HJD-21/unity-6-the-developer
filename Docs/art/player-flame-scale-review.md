# 플레이어 작은 불꽃 크기 보정

담당: 이영빈 · 2026-10-31.

위쪽 이동·공격·수리, 위쪽 대각선 이동·스패너, 위쪽 좌우 기울임에서 작게 보이던 불꽃 38장을 기존 큰 이동 불꽃과 비교해 넓고 길게 수정했습니다. 양쪽 분사구는 가방 아래 모서리에 유지하며, 불꽃 축은 몸통의 기울기를 따릅니다. 좌우 자세는 각각의 원본을 사용합니다.

프레임의 캔버스 160×160, 32 PPU, Point 필터와 기존 GUID를 유지했습니다. 불꽃 그림은 내장 `image_gen`으로 편집하고 고정 격자로 분할·축소했습니다. 색상으로 다리나 몸체를 추정해서 지우는 방식은 사용하지 않았습니다.

38장 모두 수정 전·후를 시각적으로 확인했습니다. 대각선에서는 커진 분사가 뒤쪽 다리 일부를 가릴 수 있습니다. Unity 플레이 검증은 실행하지 않았으므로 에디터에서 실제 표시 크기와 이동·공격·수리 전환을 확인해야 합니다.
