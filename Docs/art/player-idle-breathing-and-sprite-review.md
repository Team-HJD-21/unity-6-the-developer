# Player 대각선 대기와 전체 스프라이트 검토

후속: 2026-10-30 [독립 좌우 자세와 제트팩 분사구](player-independent-facing-review.md)를 적용했다. 아래 반전 공유와 팔레트 보정은 10/29 작업 당시의 기록이며, 현재 연결·PNG 해시는 후속 기록을 따른다.

담당: 이영빈 · 2026-10-29 · PR #575 후속.

상태: 현재 브랜치의 구현·제작 기록. Unity 플레이 검증 전.

## 대기 애니메이션

현재 Player 외형을 참조해 총기 대기와 스패너 대기의 위·아래 오른쪽 대각선 호흡 프레임을
각 4장 제작했다. 총 16장이다. 기존과 같은 160×160, 32 PPU, 중앙 피벗, Point 필터를 사용한다.
호흡은 작은 가슴·어깨 움직임이며 걷기나 공격 동작을 추가하지 않는다.
기존 0.8초 루프와 Animator 상태·AnimationClip GUID를 유지한다.

프레임은 `Assets/Art/Sprites/Player/Motions/V2/DiagonalIdle/`에 있고 생성 원본은 같은 V2의
`Source/IdleBreathing_*_Source.png`다. 무기는 몸체에 그려 넣지 않고 각 무기 Appearance에
새 몸체 프레임과 기존 분리 무기·총구 설정의 대응을 추가했다.

## 좌우 한 쌍

`Right↔Left`, `UpRight↔UpLeft`, `DownRight↔DownLeft`는 같은 Sprite 프레임을 사용하고
왼쪽 클립의 `SpriteRenderer.flipX`를 반전한다. 기존 이동·공격·수리·후진을 포함한 38개 클립에
적용했다. 좌우 이동 기울임도 함께 대응시킨다. 예를 들어 `HoverFireLeanRight_Left`는
`HoverFireLeanLeft_Right`를 반전해 몸이 쏠리는 방향을 유지한다. 위와 아래는 별도 원본을 사용한다.

무기 표시는 기존 `PlayerWeaponVisual`이 몸체 flipX를 따라 위치·회전·Sprite를 반전한다.
Weapon Rig의 왼쪽 총구 표도 대응하는 오른쪽 자세의 X를 반전하고 Y를 같게 맞춘다.
그림자 접지 X도 같이 반전한다. 물리 루트와 수동 Collider의 설정은 변경하지 않는다.
기존 왼쪽 PNG는 이전 제작 자료로 남기지만, 대응 클립은 오른쪽 원본을 참조한다.

## 전체 검토와 손상 보완

변경 전 클립에서 참조한 PNG 264장(몸체 244장, 탄환·이펙트 20장)을 접촉 시트로 검토했다.
이후 원본마다 다른 모습을 만들기보다 좌우 한 쌍의 표시를 통일하는 방향으로 정리했다.

아래 방향 총기 이동 4프레임에서는 다리 내부가 투명해지고 윤곽이 끊긴 부분을 확인했다.
내장 이미지 생성 도구로 다리 연결을 보완하고, 기존 머리·손·상체·무기 그립을 보호한 채
하단 다리 영역만 합성했다. 생성 이미지를 통째로 덮어쓰지 않는다.

이동·부유 프레임 124장은 기존 불꽃 형상을 유지하면서 외곽을 옅은 청록 계열로 맞췄다.
불꽃의 색 보정은 RGB만 바꾸며 Alpha를 지우거나 허벅지의 흰색을 따라 확장하지 않는다.
짙은 몸체 외곽선이 감싸는 영역은 보호한다. 다리 사이·손 사이의 자연스러운 빈 공간을
다리 손상과 구분하며, 투명한 부분을 무조건 채우지 않는다.

원본·프롬프트·참조·변경 목록은 [제작 기록](player-idle-breathing-and-sprite-review.json)에 있다.
이전 레이어·불꽃 제작 기록의 해시와 사용 프레임 수는 그 제작 시점의 값이며, 이번 변경은 위 기록으로 추적한다.
호흡·다리 수정의 이미지 출처는 `host_image` / 내장 `image_gen`이다.
불꽃 보정은 기존 그림의 팔레트 처리다. 외부 영상 API·Grok을 사용하지 않았다.

## 검증 범위

- 컴파일과 에셋 정적 참조 검사를 수행한다. Unity 임포트 및 실제 플레이 통과와 구분한다.
- 회귀 테스트는 좌우 Sprite 공유·flipX 반전, 대각선 호흡 4프레임, 물리 루트 고정을 확인한다.
- 에디터에서 대각선 대기 중 무기 그립, 첫 발 총구, 좌우 후진, 불꽃과 허벅지 구분을 확인해야 한다.
