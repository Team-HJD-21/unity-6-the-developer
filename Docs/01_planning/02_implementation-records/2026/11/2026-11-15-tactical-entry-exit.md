# 전장 진입 중 지도 차단과 종료 파동 반전

사용자 요청: 전장 진입 문구가 표시되는 동안 지도를 사용할 수 없어야 하며 지도 종료는 진입과 반대 방향으로 보여야 한다.

## 변경

- `TacticalCommandController`가 같은 HUD의 `CombatHudIntro.Completed`를 읽는다. 문구·문구 소거·HUD 스캔이 모두 끝나기 전에는 지도 버튼을 숨기고 M 입력을 처리하지 않으며 직접 `Open()`과 오래된 버튼 이벤트도 거부한다. HUD 진입 연출이 없는 격리 화면은 기존 조건을 유지한다. 이동/공격의 공용 입력 lease는 추가하지 않는다.
- 진입 연출은 기존 순서를 유지한다: 전면 육각선0.12초 → 카메라 교체/유지0.06초 → 중앙에서 바깥으로 소거0.42초 → 지도 UI 공개.
- 종료는 역순이다: 가장자리 잔상에서 중앙으로 육각선을 채우기0.30초 → 중앙까지 채워진 뒤 필드 카메라 복구/유지0.06초 → 전체 육각선 소거0.12초 → 필드 HUD와 조작 복구. 기존 총 종료 시간0.48초는 유지한다.
- 종료 초기값은 유지 상태에서만 준비한다. 진행 중 재요청은 현재 Cover/Reveal에서 이어가며 과거 완료 콜백을 남기지 않는다. 외부 메뉴/사망/Scene 해제의 즉시 정리도 유지한다.
- 기존 투명 육각선 셰이더/재질을 사용하므로 새 래스터·프리팹·검은 배경·scene 굴절 효과를 추가하지 않는다.

`TacticalModeEffect`의 CoverSeconds/HoldSeconds/EnterSeconds/ExitSeconds가 기존 Inspector 편집 접점이다. 종료는 ExitSeconds를 먼저, CoverSeconds를 마지막 소거에 사용한다.

## 검수 조건

`StageTurretCommandHudTests`에 미완료 연출의 버튼/M/직접 호출 차단 및 완료 후 동일 M 입력 허용, 종료 경계의 단조 감소와 카메라 복구 시점을 검사하는 사례를 추가했다. 느린 Editor에서 준비 중 연출이 지나가지 않도록 해당 검사만 Scene 로드 후 런타임 Intro를 대기시킨다. 테스트 변경은 Scene/Prefab에 저장하지 않는다. 실제 기본3초 문구의 검수는 별도 정상 재생 캡처로 구분한다.

기존 테스트는 HUD 완료를 기다린 뒤 지도 동작을 검사한다. OS 포인터가 스킬 도크 위에 남아 선택 UI를 열던 조건은 테스트용 InputSystem 포인터로 격리하고 종료 시 복구한다. OS 입력 설정을 변경하지 않는다. 메뉴 차단 검사도 Player의 투영 필드를 직접 덮는 대신 실제 App 입력 lease를 사용한다.

검증 산출물은 Git 제외 `Docs/Local/Validation/TacticalEntryExit20261115`에 보존한다. 최종 실행 결과는 아래에 기록한다.

## 최종 결과

- 고유12개 씬 검사 통과를 분할 실행으로 확인했다. 전체 실행은10/12였고 남은2개는 테스트 프레임 대기를 고친 뒤 각각1/1로 통과했다. 단일 전체 실행12/12나 전체 프로젝트/Standalone 빌드 통과라고 보고하지 않는다. 가상 키 상태와 메뉴 lease가 정상 Player Update에 반영될 때까지 기다리도록 한 테스트 수정이며 제품 입력 경계를 완화하지 않았다.
- 기본3초 문구의 정상 재생259개 프레임 표본에서 미완료 중 직접 열기258회 모두 거부, 미완료 중 열린 지도/보이는 지도 버튼0건을 확인했다. 문구·HUD 스캔의 시간 설정을 바꾸지 않은 실제 Scene 재생이다. 스크립트로 오래된 버튼 이벤트도 호출했으며 OS 클릭 검수와 구분한다.
- OS 마우스로 지도 열기/닫기2회 전환을 실행하고77개 표본과 Game View 연속 이미지를 수집했다. 종료 Reveal이1에서0으로 감소하는 동안 지도 카메라를 유지하고, 중앙까지 채워진 뒤 Player 카메라로 복구했다. 중앙이 아직 열린 상태의 조기 카메라 복구0건, 전환 중 Command UI 표시0건이다.
- 종료 중간 캡처의 가장자리 육각선 → 중앙까지 채워진 육각선 → 필드 화면 순서를 직접 비교했다. 배경은 계속 보이며 끝난 뒤 육각막/지도 표식이 남지 않았다. M은 자동 InputSystem 검사로 확인했고 물리 키보드 검수라고 쓰지 않는다.
- scoped diff 검사 통과, 기존 staged8개의 patch 동일을 확인했다. 이번 수정은 제품 코드2개·기존 테스트1개·관련 문서에 한정하며 Scene/Prefab/Material을 저장하지 않았다. Play 종료·Startup 활성·미저장 변경 없음으로 복원했다. 위 단독 검수 시점에는 커밋·푸시 전이었다. 이후 사용자 승인에 따른 전체 수정 업로드 범위와 추가 검증은 [전환 중 HUD 숨김 기록](2026-11-15-tactical-transition-hud.md)을 따른다.
