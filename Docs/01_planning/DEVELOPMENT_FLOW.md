# 개발 흐름과 문서 반영

기준일: 2026-11-05 · 상태: 현행 운영 기준

1. 게임 규칙은 Product Plan, 공용 계약은 영역 API, 실제 작업 상태는 Issue/Project에서 확인한다.
2. 회의 원본은 공유 드라이브에 보존한다. 확정·제안·미결정을 나누고 확정 변경은 해당 기준 문서 PR로 제안한다.
3. 새 기준 문서를 작성할 때 기존 버전은 스냅샷으로 보관한다. 기존 페이지에 날짜별 정정을 계속 누적하지 않는다.
4. 사용자 작업을 보존한 기존 작업 트리의 문서 브랜치로 작업한다. main 직접 push·자동 병합은 하지 않는다.
5. 링크·문서 충돌·필수 검사를 확인하고 사용자 지시로 병합된 뒤 공식 사이트에 반영한다. 미병합 문서를 현행으로 표시하지 않는다.
6. Notion에는 목표·담당 작업·최근 합의·공식 링크만 유지한다. 원문 복제를 새로 만들지 않는다.
7. 기획·구현·정적 검사·Unity/네트워크 실행·PL 인수는 각각의 증거로 기록한다. 이번 문서 정리는 게임 완료/인수 선언이 아니다.
