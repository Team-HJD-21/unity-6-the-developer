## 2. 합의한 Spaceship / Control Unit 경계

- Spaceship은 언제든 출입 가능한 Hub다. Player 연구·성장, 정보와 향후 SOS 진입을 맡는다.
- Control Unit은 현장의 전력·터렛 운용 편의 기능을 맡는다. 지역 해금은 ②를 채택할 때의 후보 기능이다.
- Control Unit은 별도 내부 Map 없이 현장 상호작용으로 처리하는 방안을 검토한다.
- Spaceship 진입 중 시간 진행, 전장 상태, 체류 위험과 메뉴 제한은 미정이다. 정비를 위한 잦은 왕복은 피로도를 검증해야 한다. (녹음 01:07:22~01:21:36, 01:32:07~01:32:46)

## 3. 승패·터렛 상태

- 최종 승리 판정은 행성 전체 정복, 외곽 터렛 확보 뒤 Boss, Boss 처치 등을 비교한다.
- Player 사망과 Control Unit 파괴를 패배 조건으로 논의했지만 결과를 같게 할지, 패배 후 무엇을 유지할지는 미정이다.
- 터렛 공격·파괴·고장과 수리·재활성화에 시간 등의 비용을 두는 방향을 검토한다. 15초 수리와 터렛 5개 묶음은 예시 수치다. (녹음 55:28~01:03:05)
